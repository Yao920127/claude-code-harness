# Agent Note: 回應式 Sidebar 與注入的標籤資訊

Status: implemented

[English](2026-09-07-sidebar-responsive-tab-info.md) | 中文

## 問題

標籤擴充功能需要一致的所屬窗格與 Sidebar 即時資訊，而不依賴不斷增長的 owner props。工作區也需要適應有限的視口空間，同時保留內容，並且不重新開啟使用者已經關閉的 Sidebar。

## 決策

Slot 框架注入一個 `useTabInfo()`，返回巢狀的 `sidebar`、`panel` 與 `tab` 欄位。它組合框架繫結的佈局與導航 hook；擴充功能既不自行訂閱，也不接收服務物件。正文可見要求 Sidebar 展開且標籤活躍；標題可見不要求標籤活躍。隱藏或切換 Session 保留標籤生命週期。關閉記錄會中止其 signal。標籤動作始終繫結到所屬 Session。Store 收編是外掛組裝的私有能力，不是公共控制器操作。

框架先縮小右列，再關閉右列，最後才縮小工作階段區，以保護工作階段區的 400px 寬度。右列首次開啟偏好為視口的 45%，此後按畫素保留，下限為 300px，上限為視口的 70%。在寬度至少為 1024px 時，左列保持自身偏好。關閉是被記錄的狀態：變寬不會開啟右欄，使用者動作或顯式 Session API 可以開啟。[佈局持久化與 provider 恢復](2026-09-14-sidebar-layout-provider-recovery.zh.md)負責重新整理後的佈局還原；框架寬度偏好仍根據視口初始化。

全螢幕使用同一棵已掛載內容樹，覆蓋視口並保留底層列的佔位。在 768px 以下開啟會選擇自動全螢幕；在此寬度下退出全螢幕會關閉 Sidebar。變寬可以結束自動全螢幕，但保留手動選擇的全螢幕。產品允許兩個水平窗格，初始按 50/50 分割，分割線範圍為 20–80%；窄窗格拒絕新分欄。通用停靠引擎保留其獨立能力。 全螢幕入場先完成滑入，再報告底層軌道；被覆蓋的寬度變化瞬間完成，因此入場及返回普通模式都不暴露底層重排。達到兩格預算時隱藏分欄控制元件；單格寬度不足時仍顯示停用控制元件。 退場時，框架先準備目標佈局，再讓覆蓋層退出：關閉不留右軌道，恢復保留普通軌道。清除全螢幕報告時仍保留過渡抑制，直到下一次幾何操作才結束。

本決策取代[標籤型別與導航](2026-09-05-sidebar-tab-types-and-navigation.zh.md)的平鋪 owner props 選擇，以及[停靠基礎設施](../feature/2026-09-04-right-sidebar-docking-infrastructure.zh.md)中的無讓步、覆蓋模式和產品窗格上限。它們的註冊、記錄生命週期、狀態所有權與引擎選型理由繼續有效。

## 考慮過的替代方案

**平鋪資訊 props 或三個獨立 hook。** 一個巢狀讀取介面按三個所有權層級分組，允許增加欄位而不增加 props 或讀取介面。

**視口變化後自動重開。** 這會讓開啟依賴佈局歷史，而不是顯式動作。關閉的 Sidebar 保持關閉，同時保留內容。

**獨立的全螢幕內容樹。** 重新掛載會打斷標籤區域性狀態。因此由同一元素改變呈現方式。

## 後果

標籤擴充功能使用框架注入的讀取介面，自身 store actions 與 `tab.actions` 保持分離。佈局、seat 與停靠測試覆蓋列寬讓步、顯式重開、正文與標題可見性、標籤生命週期、水平放置區與分割比例；瀏覽器測試覆蓋組裝後的應用。緊湊移動端控制元件與佈局持久化不屬於本決策。
