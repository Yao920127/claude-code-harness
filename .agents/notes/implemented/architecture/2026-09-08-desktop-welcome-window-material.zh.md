# Agent Note: 桌面歡迎視窗材質

Status: implemented

[English](2026-09-08-desktop-welcome-window-material.md) | 中文

## 問題

桌面歡迎介面的設計要求整個視窗模糊其背後的桌面。Chromium 背景濾鏡只能取樣渲染器內部的內容。憑證設定還需要明確的啟動歸屬，避免跳過原生引導後又出現 Web 彈出視窗。

## 決策

[Electron 歡迎視窗](../../../../apps/desktop/src/welcome-window.ts)負責原生材質和視窗控制元件。獨立打包的 React 渲染器提供入口、帳號登入狀態和 API Key 表單。它與 Web UI 共用 `StateDot` 載入元件，不啟動 Web 外掛圖。Desktop 建置將本地 JavaScript 和 CSS 輸出到 `lib/welcome`，並納入應用安裝檔；文件繼續使用禁止網路存取的內容安全策略。窄介面 preload 提供強型別桌面文案、僅寫金鑰操作和跳過操作；IPC 拒絕其他視窗和子 frame。每個沙箱 preload 都獨立打包，因為 Electron 受限的 require 無法載入同目錄中的拆分模組。Electron 主程序透過共享 Web 啟動 URL 認證，並透過現有設定和憑證 RPC 方法解析官方提供者的引用。[Web 薄殼](2026-09-10-desktop-web-wrapper.zh.md)負責 HTTP 服務；引導不增加 Host 端點或子程序 IPC 操作。回應只包含中繼資料或安全結果，不包含金鑰或提供者的私有診斷。

冷啟動在帳號憑證與模型 API Key 均未設定時開啟入口。儲存會在持久化成功後進入工作區；跳過會直接進入，不儲存草稿或憑證入口完成標記。下次程序啟動時會重新檢查憑證。Desktop preload 標記抑制自動 Web 憑證步驟和歡迎須知；設定與顯式 API Key 編輯仍然可用。[Desktop 引導決策](../feature/2026-09-16-desktop-onboarding.zh.md)負責帳號登入後獨立的裝置本地介紹流程。其他原生殼可以透過 Models Host 外掛注入頁面的 `credentialOnboarding` 值僅停用憑證步驟。模組圖傳遞的是包標識，而不是任意 Host 設定，因此單獨設定 Host 行不會設定其 Client 半部。[帳號提供者](2026-09-14-deepseek-account-login.zh.md)提供登入與退出登入狀態，同時保留獨立儲存的 API Key。

生成的開發專案沿已宣告的 workspace 依賴建立連結，因為單獨依賴 pnpm 的提升索引會漏掉設定外掛。

Desktop 在開啟歡迎視窗前讀取共享的 `locale.preference`。Client 在掛載前等待隔離 preload 返回該偏好和同一系統語言順序，之後將解析後的語言變更通知桌面殼。只有設定中的明確選擇會寫入偏好；自動檢測保持臨時狀態。桌面殼自帶英文和繁體中文詞典，因此僅在 Client 中提供的語言包會在原生視窗退回到受支援的系統語言。

歡迎流程與啟動恢復共用 Desktop 後端控制器。Host 啟動期間，主視窗在螢幕外載入恢復文件；失敗時顯示該文件，成功後讀取憑證和語言，再選擇歡迎視窗或工作區。恢復操作保留控制器的序列重試與等待子程序退出的行為。應用 preload 只向殼文件提供恢復控制元件，只嚮應用文件提供語言橋接。

## 考慮過的替代方案

**僅使用 CSS 背景濾鏡。** 它無法模糊其他應用視窗或桌面，因此不能提供所需的原生效果。

**持久化憑證入口完成標記。** 跳過原生憑證入口只對目前程序有效；保留標記會在使用者仍無憑證時抑制下次冷啟動選擇。帳號介紹流程的獨立完成標記不會繞過此認證判斷。

**同時保留原生與 Web 憑證彈出視窗。** 兩者獨立的完成狀態會在跳過原生引導後再次要求輸入金鑰。組合將憑證引導交給單一歸屬方。

**繪製替代紅綠燈。** 原生控制元件保留平臺視窗行為和無障礙能力。它們的尺寸與視窗外部圓角遵循作業系統，不嚴格複製 Figma 幾何參數。

**獨立的預覽回呼。** 純視覺預覽中的跳過無法證明能進入工作區，還會掩蓋啟動依賴缺失。預覽使用與產品相同的回呼和 Host。

## 後果

原生模糊強度和字型退回因系統而異。主視窗沿用共享的 sidebar vibrancy；全窗引導保持渲染器透明，不額外疊加底色。Windows 合成效果需要平臺驗證。所屬目錄內的文字預期覆蓋兩頁和兩種語言，建置後 Host 的驗收覆蓋憑證跨重新啟動持久化。帳號退出登入保留獨立的 API Key。引導展示不會生成 Session 事件。
