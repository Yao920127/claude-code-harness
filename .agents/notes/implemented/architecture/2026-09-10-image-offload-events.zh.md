# Agent Note：持久圖片省略事件

Status: implemented

[English](2026-09-10-image-offload-events.md) | 中文

## 問題

請求可能超過圖片路由的位元組或圖片數量預算。每次請求重新計算省略字首，會讓路由切換、內聯退回或壓縮恢復先前省略的圖片。模型可見的圖片集合因此取決於未記錄的請求準備過程。[統一圖片流水線](../feature/2026-08-20-unified-image-request-pipeline.zh.md)負責附件歸一化與請求版本，持久省略需要單獨記錄決策。

## 決策

`dsh-compaction-image-offload` 在 `agent/request-error` waterfall 上負責恢復。`IMAGE_OFFLOAD_REQUIRED` 失敗提供 `offloadImages`，外掛按目前 surface 順序選擇該數量最舊且仍保留的輸入圖片出現位置，追加一個 `image/offload` 事件，再返回 `retry`。Assistant 輸出圖片不參與選擇。沒有保留的輸入圖片時，外掛委託後續處理。其他失敗不進入這項恢復。圖片省略不消耗提供者重試預算，也不產生 `llm/retry`。

摘要請求不經過 agent 錯誤 waterfall。`dsh-compaction-basic` 保留完整的 `LlmFailure`，檢查取消和選區穩定性，再攜帶所選事件序號觸發同步的 `compaction/summary-error`。同一個圖片省略外掛只在選區內記錄省略。同步恢復使穩定性檢查與決策相鄰執行。後端隨後重新派生輸入並計價，包括判斷摘要是否縮短輸入的基準。每次重試都必須繼續省略圖片，無圖可省略時委派失敗。後續摘要失敗或取消仍保留已經記錄的省略，因此命令錯誤不聲稱工作階段未變。

事件載荷為 `{ targets: [{ seq, imageIndexes }] }`。每個目標指向目前的 `user/message` 或 `tool/result` 節點。索引從零開始且嚴格遞增，按內容深度優先順序列舉所有圖片，包括 tool-role 結果內容和先前省略的圖片。相同附件 ID 的多次出現分別計數。位置替換改變 surface 順序後，明確選擇仍沒有歧義，附件 ID 或原始日誌字首無法標識這個集合。

事件不帶 `surfaceOp`，不建立訊息，也不替換訊息節點。外掛的純投影在 Session 提交事件前驗證全部目標，拒絕缺失或已被遮蔽的節點、輸出圖片、重複目標、無效索引和已被省略的位置。重建過程派生不可變訊息副本，將記錄的位置標為 `ImageBlock.offloaded: true`。原始事件、訊息 ID、來源和未受影響的內容塊保持不變。恢復、分叉和回放從日誌應用相同的選擇。

compaction 外掛擁有選圖、事件宣告、圖片驗證與投影，以及重試策略。[外掛擁有訊息投影](2026-09-11-plugin-owned-message-projections.zh.md)負責通用 Session 整合和顯式獨立裝配，取代由核心負責解釋的職責劃分。實例方法 `deriveEventMessage()` 與 `deriveMessages()` 返回派生訊息，純重建函式將 `foldSurface(events, projections).projectedMessages` 傳給匯出的 `deriveEventMessage()`。需要保留圖片的改寫必須讀取派生訊息，包括工具結果裁剪和摘要輸入。

訊息替換和圖片省略事件都會推進 `contentGeneration`，使歷史快取和請求系列重新整理。`replaceGeneration` 只隨替換推進，圖片省略不能被判斷為文字壓縮成功。請求設定未變時寫入原因是 `series` 的 `request/header`，設定同時變化時攜帶 `startsSeries: true`。

介面卡只準備保留的圖片，將帶標記的位置渲染為包含目前執行環境存取路徑的 `offloadedImageText`。路由本地預算檢查報告所需數量，包括內聯退回的更低預算，但不編輯歷史。這些檢查是暫時方案，未來提供者報告無法快取的圖片時，可以替代本地計數，無需把持久決策移入介面卡。

Token 計量將選擇應用到受影響節點的圖片出現位置，不替換節點身份，也不修改已有用量錨點快照。路由計價以佔位文字替代圖片費用。固定結構啟發式不計 `offloaded` 標記，因此圖片省略不改變該啟發式，也不需要 `compaction/prune` 的遮蔽價格。上下文壓力和分類明細檢查點版本遞增，拒絕曾將該標記計入的快取估算。

`image/offload` 是讀取時必須識別的事件。它增加已知事件型別，不改變 Session 信封或操作語法，因此不推進 `SESSION_FORMAT_VERSION`。不認識該型別的讀取器會拒絕日誌，避免靜默恢復已省略的圖片。

## 考慮過的替代方案

**複用 `compaction/prune` 和 `surfaceOp: replace`。** [已歸檔的替換設計](../../archived/architecture/2026-09-02-durable-image-offload.md)記錄攜帶圖片的完整訊息副本，把圖片省略與節點替換和遮蔽價格計量繫結。專用事件表達被省略的圖片，保留訊息身份，重試策略仍留在同一個外掛中。

**記錄單次請求的投影結果。** 不影響後續派生的記錄無法阻止省略的圖片返回。記錄完整請求體會重複訊息歷史，而決策只需要圖片出現位置索引。

**使用附件 ID 或單個分界點。** 附件可能重複出現，surface 順序也可能與事件序號順序不同。逐節點記錄明確索引能夠區分這些情況，無需在每次替換後重新定義分界點。

**把選擇移入迴圈或介面卡。** 請求錯誤擴充功能點已經負責修復與重試。介面卡知道路由預算，外掛知道工作階段輸入順序，兩者都不需要在共享迴圈中加入路由策略。

## 影響

路由預算增加、內聯退回結束或壓縮減少上下文時，省略仍然有效。省略不刪除附件位元組。讀取佔位文字中的存取路徑會建立新的圖片出現位置，可以獨立保留。執行環境路徑仍在序列化時解析，與保留圖片的標識文字一致。這個事件記錄選擇的圖片集合，不記錄檔案系統對映。

Session 呼叫已註冊的純投影，並維護一個內容版本訊號。重建模型輸入的消費方必須使用派生訊息。面向人的檢視仍可從不可變事件顯示原始圖片。外掛記錄省略時不需要 token-meter 或 compaction 服務。

## 測試

外掛的投影測試覆蓋巢狀和重複圖片、原子拒絕、快取失效、純摺疊、恢復、分叉及原始事件不變。恢復測試覆蓋連續失敗、目前 surface 順序、無圖可省略時的恢復、新請求頭和釋放。Token-meter 測試在僅重計所選位置價格時保留節點身份和已有用量錨點。工具結果裁剪和壓縮測試保證後續改寫讀取派生歷史。TypeScript 和 Python SDK 預期輸出透過釋出的 profile 覆蓋必需事件。
