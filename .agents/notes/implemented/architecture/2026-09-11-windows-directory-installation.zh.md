# Agent Note: 暫存完成後替換 Windows 應用目錄

Status: implemented

[English](2026-09-11-windows-directory-installation.md) | 中文

## 問題

Desktop 分發包包含數千個小檔案。先解壓到臨時目錄，再將每個檔案複製到安裝位置，最後刪除臨時樹，會重複執行檔案系統操作。Windows 上一份 616,701,792 位元組、11,735 個檔案的載荷經過這三個階段分別耗時 101.235、79.203 和 114.391 秒，其中複製佔 70.296、56.688 和 85.281 秒。這些元件測量不包括舊版解除安裝、註冊、啟動，也沒有清空快取。

## 決策

[NSIS 介面卡](../../../../apps/desktop/scripts/windows-directory-installer.mjs)保留 electron-builder 的安裝器、簽名解除安裝器生成、註冊、快捷方式和更新快取。它在停止舊應用前，將完整新應用暫存到目標目錄旁。[目錄事務](../../../../apps/desktop/scripts/installer-directories.nsh)把舊目錄改名為唯一備份，將新目錄改名為正式目標，並在啟動前刪除備份。兩次改名都位於目標卷。這替代了[打包記錄](2026-08-25-electron-desktop-packaging-and-updates.zh.md)中基於複製的安裝決策。

安裝器嵌入固定版本的 7-Zip 命令列工具，為簽名釋出簽署其私有副本，並攜帶許可證文字。Windows 在複製後的執行時可執行資源簽名完成後記錄檔案清單。解壓結束代碼非零時，舊應用保持完整。上游安裝器退出前顯式清理目錄，也覆蓋靜默取消。同路徑升級跳過舊解除安裝器，避免其提前刪除復原副本或註冊資訊。不同路徑和安裝範圍遷移保留 electron-builder 的舊解除安裝器行為；目錄復原不會撤銷這些解除安裝操作。

## 影響

目錄清理（包括解除安裝）使用 Windows 擴充功能長度路徑，覆蓋深層依賴與備份字尾。新目錄替換失敗時，安裝器嘗試恢復已改名的舊目錄。如果另一個程序阻止恢復，完整備份仍保留。程序被強制結束或斷電可能留下暫存或備份目錄；安裝器不承諾跨兩次改名的崩潰原子性。事務只改變安裝檔案，不改變外部 Desktop 外掛 profile 或產品資料。

## 考慮過的替代方案

- **直接覆蓋執行中的安裝目錄。** 現有檔案佔用探針證明，`Nsis7z::Extract` 可能保留舊檔案而不設定 NSIS 錯誤標誌。使用具有退出狀態的工具進行暫存，可以避免接受混合版本安裝。
- **解壓前刪除舊版本。** 壓縮包損壞或寫入失敗時，會在替換就緒前移除唯一可用版本。
- **把 Host 放入 ASAR。** 原生模組、包解析和子程序路徑需要單獨驗證；目錄替換保留資源佈局。

## 驗證

[原生目錄 smoke](../../../../apps/desktop/scripts/smoke-installer-directories.ps1)在私有目錄中呼叫生產宏。它覆蓋首次安裝、升級時刪除過時檔案、目錄佔用失敗、第二次改名失敗後的恢復，損壞歸檔，以及取消清理。範本測試固定暫存早於關閉應用、正式替換早於註冊。簽名的 0.1.5-rc.2 安裝器在 Windows 上透過了首次安裝、同路徑升級並移除過時檔案、檔案佔用失敗後保留舊安裝、變更安裝位置及完整解除安裝。每次安裝檢查都將全部 11,736 個載荷檔案與打包目錄比對，並驗證程式、解除安裝器簽名及註冊資訊。已安裝執行時透過了原生依賴、Web 前端、外部外掛路由及實際 Electron 視窗啟動和退出檢查。最終安裝器的一次樣本中，首次安裝耗時 38.0 秒，同路徑升級耗時 27.5 秒，不包含總和檢查碼啟動，未清空快取。這些完整安裝器觀測與上面的元件基線分別記錄。線上更新下載和從歷史已釋出版本升級仍屬於釋出驗收。
