# Agent Note: DeepSeek 帳號瀏覽器登入

Status: implemented

[English](2026-09-14-deepseek-account-login.md) | 中文

登入申請儲存發起介面的用戶端中繼資料，使瀏覽器授權跟隨桌面或設定頁的語言，不依賴平臺預設值。

## 問題

桌面登入必須在瀏覽器、UI 和 Host 之間保留本地取消意圖，並只在憑證儲存後宣告成功。

## 決策

帳號服務定義將 UI 和模型使用方與平臺協定實作分開。平臺提供者註冊 AuthorizationFlow，並儲存按所有者定址的 GrantRecord。帳號是否存在從儲存派生。登入嘗試保留在記憶體中，透過帳號 Remote 控制器提供安全快照。

本地取消具有決定權。提供者停止回呼並忽略遲到的兌換結果；auth_cancel 使用 authorize_id 和原始 PKCE verifier 作廢遠端申請及未兌換的 code。後臺請求不延遲本地取消，失敗也不會恢復登入。session.commit 在第一次 await 前同步准入持久化，並拒絕已取消的流程。准入後的取消等待提交結果。回呼只有在授權結束確認儲存後才跳轉 auth_exchange.biz_data.authorized_url。

授權在 Host webServer 上註冊臨時 /oauth/callback 路由。已授權驗證的發起用戶端提供瀏覽器可存取的本機 HTTP 來源，包含 SSH 本地轉發埠。不支援非本機域名反向代理。清理僅移除路由，保留共享連線。兌換失敗返回 Web 登入介面，或透過帳號狀態聚焦 Desktop；重試由使用者明確發起。PKCE 私密資料不經過 UI 傳輸。模型和檔案請求的 token 僅為設定的 inferenceOrigin 解析，預設為 `https://api.deepseek.com`；請求拒絕重定向。顯式設定其他來源時，要求授權由設定的 Platform 來源簽發，因此僅修改請求地址不會轉發帳號憑證。本機開發授權記錄不能認證生產請求。API Key 引用獨立儲存。

平臺導航與授權共享 Cordis 設定中同一個經過驗證的 platformOrigin。私有 profile patch 或環境表示式提供部署來源，開發地址不進入儲存庫。

Platform 用戶端身份屬於發起呼叫的介面，而不屬於 Host。每個帳號操作都攜帶呼叫方的用戶端版本、目前語言和目前 UTC 偏移，provider 據此與組合出的原生平臺推導該次呼叫的五個 Platform 用戶端請求頭。用戶端身份請求頭覆蓋部署設定中的同名請求頭，因此一個被多方共享的 Host 報告的是每次請求的發起介面，而不是它上一次見到的呼叫方；更新策略用戶端對已安裝的殼沿用同一組請求頭語義。PlatformSession 有意不攜帶呼叫方身份；內嵌用戶端自行組裝同樣的五個請求頭，並僅在設定來源傳送。

## 替代方案

把協定放在 Electron 會為 Web 使用方重複實作，並讓外殼擁有憑證。把 token 放入 DEEPSEEK_API_KEY 會丟失帳號授權與使用者 API Key 的區別。在持久化前將瀏覽器回呼視為成功會產生虛假成功。等待遠端取消確認會使本地取消依賴網路。在 Host 中記住一份用戶端身份，會讓共享該 Host 或經轉發接入的其他呼叫方被標錯。這些方案均被拒絕。

## 影響

退出登入先刪除本地授權，再使用捕捉的 token 呼叫 Platform POST /auth-api/v0/users/logout。遠端失敗不會恢復登入態。首次請求失敗後，提供者最多重試五次，使用可設定的指數退避，預設從一秒開始。重試任務只保留舊 token，不改變後續登入態，並在提供者關閉時結束，不持久化。本地憑證刪除成功後才釋出已退出狀態。退出登入位於側邊欄帳號選單；帳號設定負責資料、餘額和登入。兩者透過框架 hook 讀取外掛持有的同一條 Host 狀態流。

API Key 與帳號記錄獨立儲存。帳號 token 沒有主動重新整理流程；退登重試耗盡後，已從本地刪除的 token 在遠端仍可能有效。提供者初始化時在本地丟棄與設定的 Platform 來源不同的授權，不呼叫遠端撤銷，使環境切換以未登入態啟動，而不導致 Desktop 啟動失敗。API Key 和裝置標識保留。資料與餘額介面的 HTTP 401 回應清除被拒絕的憑證，其他查詢錯誤保留登入態；授權嘗試的有效期僅適用於 token 簽發前。同一授權 token 可認證已設定簽發來源上的 Platform current 和 get_user_summary 查詢。Host 原樣保留 Platform 脫敏後的聯絡方式並丟棄回應 token；帳號變化使未完成結果失效。UI 分行顯示 normal_wallets 充值餘額與正額 bonus_wallets 贈金餘額，避免將贈金額度顯示為充值資金。

帳號外掛透過 settings.models.sign-in 提供選擇、等待、失敗和超時對話方塊。模型包保留憑證就緒檢查和現有 API Key 編輯器；設定外殼協調顯式重開，避免登入與 API Key 引導同時掛載衝突的對話方塊。

Platform 內嵌透過私有 Node IPC 將授權從 Host 傳給 Electron，再經沙箱 preload 一次性傳給受信任的 Platform 主 frame。preload 在頁面腳本執行前執行一次同步 IPC；主程序僅驗證呼叫來源並返回已準備的記憶體資料。Platform 此後同步讀取 token，無需就緒介面。初始化失敗時保留內嵌模式，由 getter 拋錯。帳號 UI 投影仍不包含憑證。Platform 文件能夠讀取此憑證，因此其腳本安全也是帳號保護的一部分；上下文隔離保護原生能力，不能隱藏有意返回給文件的 token。替換或移除授權會銷燬文件並清理瀏覽器認證；[帳號範圍內的頁面儲存](2026-09-22-platform-browser-storage.zh.md)會保留。

支援問卷僅透過顯式預填欄位接收已有的環境資訊，URL 不包含帳號 UID、token 或脫敏聯絡方式。

私有代理開發可透過 rewriteBrowserOrigin 顯式將授權頁和完成頁對映到 platformOrigin。兩者保留固定路徑和完整查詢字串；僅放寬來源而不做對映會讓瀏覽器離開設定的環境。釋出設定要求瀏覽器地址同源。

DSH 授權透過 x-dsh-auth-token 請求頭授權驗證 Platform、推理和 Files 請求，不加 Bearer 字首。API Key 繼續使用各協定的認證方式。

資料和充值錢包餘額分別透過 getProfile 與 getBalance 查詢。用戶端在各自返回時立即更新，餘額請求慢或失敗不會延遲側邊欄使用者名稱顯示。帳號變化使兩種進行中的查詢結果失效。

開發環境認證透過設定的平臺來源上的顯式 Host 請求頭 requestHeaders 完成。提供者拒絕重定向和保留請求頭覆蓋，防止開發環境 Cookie 替換帳號授權或跟隨瀏覽器跳轉地址。特定環境的認證協定不屬於帳號提供者。

內建帳號介面僅用於 Desktop：preload 橋接啟用帳號入口、設定和登入引導。普通 Web 保留 API Key 引導及標準設定入口，不訂閱帳號狀態或顯示登入。Host 協定在 auth_init 中接受 login_source（desktop 或 web）；內建介面傳送 desktop。後端接受 localhost 回呼。DSH 保留瀏覽器提供的 localhost 主機名和埠，不做 DNS 解析或 IP 字面量轉換。

macOS 開發啟動器為 `dsh://open` 註冊獨立、經臨時簽名的應用包。該應用包保留工作區入口和開發路徑，使 Launch Services 能夠冷啟動；憑證不會被複制，也不修改包管理器安裝的 Electron 應用。協定註冊指向最近啟動的開發版或打包版應用。

exchange 的 user 資料在憑證提交後供首次資料讀取使用，展示使用者名稱無需再等待一次請求。Host 僅在目前嘗試中保留篩選後的 UI 欄位，與 token 匹配並讀取一次後移除；後續讀取使用 current。缺失或格式無效的 user 不會使已成功的授權失效。

內嵌 Platform 文件在載入期間保持隱藏，因為原生子檢視會覆蓋渲染層浮層。載入完成後僅目前文件可顯示；返回或退登會使待執行的顯示操作失效。應用文件重新整理或替換、其渲染程序終止或視窗關閉時，原生檢視的所有權也隨之結束。僅依賴 React effect 清理不足以保證釋放，因為文件銷燬時可能不執行它。同文件導航和子框架導航保留檢視。

獨立的 accountRequestHeaders 將帳號資料及內嵌 Platform 流量與授權、退登分開路由。Cookie 覆蓋按名稱合併，保留部署認證。Host 透過私有程序 IPC 傳遞合併後的請求頭；Electron 僅在設定來源注入，並從 bootstrap 排除。

贈金通知使用 Platform 提供的文案和訂單標識。帳號進入登入態（已登入啟動、登入成功）時讀取一次，每次進入設定頁或從充值檢視返回時再讀取一次，不進行定時輪詢。伺服器端下發的通知立即繪製，包括在開啟的設定面板之下，因此展示從不延後。用戶端在通知卡完成一幀繪製後或使用者關閉卡片時確認訂單。不寫入任何瀏覽器儲存，因此之後再次登入會重新展示伺服器端仍在下發的訂單。確認失敗會在本次登入工作階段內按帶上限的指數退避重試。Platform 的確認記錄阻止其他裝置繼續取得通知，但介面不預留展示資格，因此確認前仍可能並發展示。僅取得成功不會記錄為已展示。

Host 將私有 Platform 工作階段繫結到帳號提供者的生命週期。提供者移除或訂閱結束時清空 Electron 工作階段；替換後訂閱新的提供者，已釋放的讀取不得釋出舊憑證。

用戶端區分外掛解除安裝和帳戶狀態流的終止錯誤。RemoteStream 在兩種情況下都會中止其訊號，因此外掛獨立記錄解除安裝狀態，保留錯誤回饋並抑制解除安裝後的報告。

## 驗證

提供者測試覆蓋真實本機回呼、錯誤 state、延遲兌換取消、憑證持久化、退出和官方來源限制。桌面測試覆蓋原生操作橋接與在地化入口。手動開發聯調使用平臺 dev middleware Mock 和真實 Electron Host，包括在瀏覽器批准前取消。生產後端憑證及安裝器 scheme 註冊仍需釋出環境驗證。
