# Agent Note: 有效工具請求頭與有狀態請求投影

Status: implemented

[English](2026-09-20-dynamic-tool-updates.md) | 中文

## Problem

外掛和 MCP 工具會在對話期間變化。不同提供者對透過歷史啟用延遲定義或移除工具的支援不同。把為提供者保留的宣告當作有效工具儲存，會使比較重複記錄移除並遺漏恢復。

## Decision

`request/header.tools` 記錄組裝得到的有效工具，不依賴模型能力。迴圈將名稱與前一請求頭比較，以 `tool-registry` 來源發出一條包含新增和移除的 `developer/message`。新增透過 `headerSeq` 引用新請求頭。定義變化仍體現為請求頭變化；名稱未變時不發出更新。現有請求頭相等判斷和請求序列規則保持有效。

`Session.toolHistory()` 快取對已提交請求頭和 developer 訊息的歸約，不依賴模型能力。首次存取恢復繼承事件；後續讀取僅處理新增事件。不可變快照攜帶初始宣告和有序更新標識，新增定義透過歷史請求頭解析。顯式新序列和保留定義變化會重建宣告。以未變化的定義恢復保留名稱時序列繼續：投影保持宣告不變，由記錄的新增在先前移除之後重新提供該工具，因此移除不會停用已宣告的工具，載入模式也不會改寫先前宣告。

迴圈和壓縮請求透過 `GenerateOptions.toolHistory` 攜帶此快照。介面卡分發時，`projectToolUpdates` 使用已準備路由的 `toolUpdate`。不支援的路由接收有效定義，不攜帶 `deferLoading` 或 developer 訊息。支援的路由延遲歷史新增；`in-history` 保留已移除定義和移除塊，`addition-only` 則省略兩者。僅保留目前序列的更新標識。缺少歷史或請求字首遺漏已記錄更新時，使用目前宣告且不傳送 developer 更新。顯式延遲載入在支援的路由上仍然可用。

DeepSeek 把投影后的更新轉換為 system 角色的 `tool_addition` 和 `tool_removal` 塊以及 `defer_loading` 宣告，在存在更新塊時傳送工具變更 beta 請求頭。預設 `deepseek-flash` 條目宣告 `addition-only`；pi-ai 不宣告模式。Chat 和 Trajectory 將 developer 訊息顯示為上下文節點，工具變更使用在地化通知：單項變更顯示工具名，多項變更顯示數量及可展開的名稱列表。

## Alternatives considered

**在請求頭儲存提供者宣告。** 為提供者保留的已移除定義不是有效工具。混合兩種含義會使持久更新依賴能力，並破壞變更檢測。

**僅憑訊息在介面卡重建定義。** 新增訊息包含名稱，不包含模式或事件級請求頭引用。Session 擁有該歷史關係；介面卡轉換投影后的請求。

**每次請求掃描完整日誌。** 快取歸約處理新事件，為普通和輔助呼叫提供穩定快照，不增加任意同步歷史讀取介面。

**在工具註冊時拒絕同名 schema 變化。** 目前不執行此限制。要讓註冊不相容工具的外掛立即收到異常，需要將新註冊與各受影響目前 surface 中已呼叫工具的歷史定義比較，同時排除已被壓縮移除的呼叫。由於實作複雜，註冊時結合歷史和作用域的檢查留待後續實作。同名 schema 變化仍被允許；它們會重建宣告，即使在 `in-history` 路由上也會使字首複用失效。

## Consequences

工具列表和邏輯更新事件不依賴能力；只有發出的宣告和訊息不同。呼叫已移除但保留宣告的工具時，透過現有 `UNKNOWN_TOOL` 路徑失敗。定義變化和不完整輔助字首為保證宣告一致而放棄字首複用；僅當請求序列繼續時，未變化的恢復才在 `in-history` 路由上保留快取字首。同時支援工具更新和歷史內系統提示詞的路由，在工具新增與提示詞變化同時發生或晚於此前提示詞更新時，保留此前訊息。不支援工具更新的路由仍在工具變化時歸併提示詞；所有路由仍在顯式新序列和 surface 替換時歸併。不增加持久欄位或 Session 格式版本。

手寫的[無介面提示詞／工具情境](../../../../snapshots/session/dynamic-tool-prompt-updates/snapshot.yml)釘住追加提示詞與延遲工具新增同時發生的行為，並驗證首次請求的訊息保持不變。它複用穩定提示詞情境的工具生命週期和 schema 期望值。

[真實 DeepSeek SDK 測試](../../../../apps/cli/tests/profiles/sdk/dynamic-tool-cache.e2e.ts) 分別在指令不變和指令同時更新時測量原生工具新增後的首次請求。獨有的使用者歷史確保僅命中共享系統提示詞快取無法滿足前序輸入斷言。移除情境檢查工具可用性，不要求保留快取；每個案例均停用重試。
