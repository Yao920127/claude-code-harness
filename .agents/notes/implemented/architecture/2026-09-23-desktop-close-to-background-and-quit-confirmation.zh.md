# Agent Note: Hide the Desktop window on close and confirm interruptible quits

Status: implemented

[English](2026-09-23-desktop-close-to-background-and-quit-confirmation.md) | 中文

視窗時序和關閉歸屬仍遵循[在 Host 啟動前顯示視窗](2026-09-09-desktop-immediate-window-and-direct-start.zh.md)；任務判定複用[更新重新啟動檢查](2026-08-25-electron-desktop-packaging-and-updates.zh.md)。本記錄部分取代[標準 macOS 視窗選單](../bug-fix/2026-09-16-desktop-window-menus.zh.md)決策：⌘W 不再透過 Electron 的 role 銷燬視窗，Dock 啟用在沒有可見視窗時重新開啟隱藏視窗，而不再只在沒有任何視窗時才建立。該記錄中的選單宣告仍然有效。

## 問題

關閉 Desktop 視窗會銷燬它。macOS 上 Host 繼續執行，但 Dock 會重建一個全新頁面，丟失目前工作階段、草稿和滾動位置；Windows 上關閉即退出應用，正在執行的任務被直接切斷，沒有任何提示。退出本身從不詢問，儘管 Host 知道哪些 agent、後臺任務和定時提醒會因此停止。

## 決策

兩個平臺上關閉主視窗都只隱藏它；頁面和 Host 繼續執行，下次顯示仍是同一個文件。Windows 增加常駐托盤圖示（單擊開啟，右鍵選單提供"開啟"和"退出"），因為 Windows 使用者習慣 × 即退出，需要一個看得見的迴路；首次關閉時先透過複用的更新彈出視窗確認，再隱藏視窗。只有點選“確認”才記錄已讀；取消時保持視窗可見。關閉視窗不傳送系統通知。macOS 沿用 Dock，不提供選單欄圖示。進入工作區前關閉歡迎視窗，Windows 上退出，macOS 上丟棄未使用的主視窗，讓 Dock 重建歡迎視窗。

所有普通退出入口都透過私有 IPC 通道向 Host 詢問兩項事實：按更新重新啟動口徑判定的執行中任務，以及本次執行中已載入工作階段裡由 `workspace/session-activity` 的 `schedule` family 報告的已掛定時器的提醒。兩項都沒有時直接退出；否則彈出一個沒有父視窗的原生訊息框，顯示三種固定說明之一，"退出"為預設按鈕，Esc 對應"取消"。重複的退出請求併入已開啟的彈框，彈框開啟期間文案凍結，批准後不再重新查詢。Host 未就緒時不可能有任務在跑，直接退出；查詢失敗或超過兩秒截止時間按執行中任務處理，因為多提示一次的代價低於無聲中斷。安裝更新的重新啟動、致命錯誤恢復、開發版重新啟動命令和作業系統工作階段結束跳過確認。

Windows 托盤點陣圖由向量圖示按七種尺寸分別渲染並提交為 ICO；Windows 上的確認框在任務對話方塊中顯示應用圖示，且始終為淺色，因為該系統控制元件不跟隨應用主題。安裝程式和解除安裝程式針對應用仍在執行的文案指向托盤。

## 備選方案

**保留關閉即退出，只在關閉時加確認。** 每次關閉都要詢問，而 Windows 使用者只要想收起視窗，後臺工作就仍會丟失。隱藏才符合"任務繼續執行"的產品要求。

**用殼的 HTML 遮罩渲染退出確認框。** 遮罩需要可見的父視窗和正常工作的渲染程序；退出必須在視窗隱藏或頁面卡死時也能完成，因此原生對話方塊才是可靠選擇。

**在 update-tasks IPC 請求上加一個標誌複用。** 退出需要第二項事實和更短的截止時間；獨立請求不觸碰更新准入鎖的語義，同時兩者共用一個關聯 id 空間。

**為托盤縮小一張大點陣圖。** 按尺寸分別柵格化向量源，才能在 100% 到 400% 縮放下都保持邊緣清晰，單次縮小無法保證這一點。

## 影響

使用者可以隨意關閉視窗；後臺任務和定時提醒繼續執行，重新開啟時恢復同一頁面。退出只在會中斷工作時提醒。Windows 在整個執行期間攜帶托盤圖示；視窗隱藏期間完成的使用者主動發起的更新下載，把安裝確認推遲到視窗再次顯示時。本次執行中從未載入的工作階段裡的提醒既不計入，也要等到這些工作階段開啟後才會繼續，而 Desktop 預設未開啟排程任務，因此排程任務文案只在該功能開啟後出現。

驗證覆蓋四種查詢結果、查詢失敗與截止時間、每個退出入口的跳過或確認、帶托盤和首次關閉確認的關閉即隱藏路徑、推遲的更新提示、Host 側查詢、IPC 關聯與截止時間，以及已提交託盤圖示的點陣圖集合。Windows 托盤和對話方塊的表現需要在 Windows 機器上以多種顯示縮放人工驗收。
