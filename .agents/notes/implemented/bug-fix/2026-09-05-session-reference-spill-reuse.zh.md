# Agent Note: 為截斷的工作階段引用複用 spill 儲存

Status: implemented

[English](2026-09-05-session-reference-spill-reuse.md) | 中文

## 問題

有界的跨工作階段預覽可能省略整條訊息，也可能省略保留訊息中的大部分文字。只看到預覽的模型需要準確瞭解省略情況，並能檢查已捕捉的文字，同時不能把其他工作階段的指令視為目前授權。源工作階段繼續推進或發生壓縮後，再次讀取無法恢復同一次觀察。

## 決策

[工作階段引用準備](../../../../packages/context/session-reference/README.zh.md)保留既有預覽策略和逐引用 JSON 位元組預算。每個被截斷的引用透過可選的 `ctx.get("spillStore")` 嘗試 `saveText`；未截斷的引用不寫入產物。完整轉錄與有界預覽來自同一份已捕捉的 user／assistant 文字投影，包含壓縮檢查點，但排除工具、推理與其他注入上下文。不發生第二次源讀取。

產物歸接收上下文的目標工作階段所有。其描述性來源是 `{ kind: "session-reference", sessionId, label }`，其中 `sessionId` 標識被引用的工作階段。[spill 儲存](../../../../packages/spill/spill/README.zh.md)在工具來源之外接受這一最小分支；不需要偽造工具名稱或呼叫 id。儲存歸屬不授權取回。

有界預覽 JSON 之外的獨立省略通知記錄精確的 `omittedMessages` 與 `omittedBytes`。通知攜帶儲存後的定位資訊和後端 `retrievalHint`，或區分未設定儲存與儲存失敗的不可用結果。該通知是同一條持久引用訊息中的模型可見內容，而不是隻供 UI 使用的中繼資料裝飾。極小的預覽預算無法移除它。儲存的轉錄攜帶包括 `capturedFormatVersion` 在內的捕捉中繼資料，以及與預覽相同的不受信任背景警告。每條訊息的 JSON 字串片段每行至多包含 64 個 Unicode 碼點；解碼並拼接後可恢復精確文字，包括原始換行。這種固定產物格式讓普通分頁檔案讀取可以取回很長的單行文字中部，而不改變預覽保留策略。

非同步儲存後的取消會阻止上下文釋出，即使儲存已經建立了產物。消費方不增加復原或刪除 API；該產物遵循後端既有過期策略。回放使用已記錄的預覽與通知，不會重複儲存或源讀取。

## 考慮過的替代方案

**另寫一個工作階段引用檔案儲存。** 不予採納，因為私有命名、工作階段級歸屬、定位指引與產物生命週期已經由 spill 儲存負責。第二套儲存會重複這些策略。

**儲存或取回時重新讀取源。** 不予採納，因為源變更可能使產物與預覽及其捕捉序列不一致。儲存原始投影可以保留該次觀察。

**把省略與取回資料放入有界預覽 JSON。** 不予採納，因為這會讓中繼資料佔用對話預算，並可能在預算最小時恰好隱藏通知。獨立的持久模型可見文字同時保留兩項保證。

**所有 spill 都使用工具來源。** 不予採納，因為工作階段引用沒有模型發出的工具呼叫。虛構工具 id 會錯誤歸屬產物，而不是描述其生產者。

## 後果

模型可以檢查預覽省略的文字，而無需增加預覽預算。通知在該預算之外增加請求 token，之後的取回再新增所請求的轉錄文字。儲存採用盡力而為策略：不可用通知如實說明無法取回，而有界預覽仍可使用。即使通知仍在持久歷史中，儲存的定位資訊也可能過期；此功能不承諾永久歸檔，也無法恢復源壓縮已經移除的內容。

## 驗證

[單元測試](../../../../packages/context/session-reference/tests/session-reference.spec.ts)鎖定省略計數、完整 Unicode 與控制字元恢復、整條訊息丟棄、三個引用的隔離、無儲存與儲存失敗、來源排除與變更隔離，以及釋出前取消。[Loader 組合測試](../../../../packages/context/session-reference/tests/loader-composition.spec.ts)使用真實本地儲存和分頁 `read` 工具，讀取巨型單行訊息的中部，並檢查儲存歸目標工作階段所有。[無金鑰錄製工作階段情境](../../../../snapshots/session/session-reference-spill/snapshot.yml)鎖定持久的模型可見引用上下文。巢狀 Windows 定位資訊迴歸覆蓋序列化提取與規範化，且不改寫無關反斜槓。回放會[規範化已知的帶引號 spill 定位資訊](../../../../packages/test-support/session-snapshot/README.zh.md)，同時保留儲存位元組數與省略計數。
