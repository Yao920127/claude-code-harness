# Agent Note: Web diff 卡片比較含上下文的內容

Status: implemented

[English](2026-09-14-web-diff-context.md) | 中文

## Problem

檔案系統結果中繼資料攜帶的前後文字片段包含未改動的上下文。把完整片段分別當作刪除和新增會錯誤標記共享行，並誇大卡片和摺疊工具行的統計。

## Decision

Web 原語透過維護中的 `diff` 庫生成行補丁，使用 `maxEditLength: 256`。每處精確改動兩側最多保留三行中性上下文；遠距離改動分成獨立 hunk，共享上下文不計入增刪統計。每個片段的新增與刪除行數超過 256 時，搜尋停止，完整新舊片段按粗粒度替換呈現，共享行也計入顯示、複製和統計。卡片與 `diffTotals` 使用同一確定性推導。這遵循[工具呈現歸屬決策](../architecture/2026-08-23-client-derived-tool-presentation.zh.md)，仍屬於 Client 呈現，不改變持久化中繼資料或公開 props。

## Alternatives considered

無上限比較會讓大量改動片段的摺疊摘要停頓。確定性的編輯距離上限能讓稀疏編輯保持精確，不受檔案長度影響；牆鍾超時可能使摘要和正文在負載下選擇不同結果。粗粒度替換在超過上限後放棄對齊，但保留全部輸入行。快取或非同步渲染會增加歸屬和失效處理，而有界比較不需要這些機制。該呈現行為無需擴充功能持久化中繼資料或維護自定義 diff 演算法。

## Measurement

本地 CPU 診斷用 esbuild（`--bundle --platform=node --format=esm`）打包生產 `DiffBlock.tsx` 入口，並在 macOS ARM64 的 Node 26.5.0 下計時 `diffTotals`。每個片段有一萬行：全部替換帶唯一索引的行、均勻分佈的 100 處替換，或交替重複的 `old`/`shared` 與 `new`/`shared` 行。不計輸入建構和模組載入；返回的統計值保持可達。這些是函式耗時，不是瀏覽器繪製或輸入延遲，也沒有作為 CI 時間閾值。

| 輸入 | 無上限毫秒數 | 有界搜尋毫秒數 |
| --- | --- | --- |
| 全部替換 | 6492.16, 6777.79, 6786.79 | 5.25, 4.66, 4.19 |
| 100 處稀疏替換 | 8.19, 4.58, 4.01 | 7.58, 4.26, 4.13 |
| 交替重複行 | 3383.13 | 10.26, 7.46, 5.52 |

上限允許全部 100 處稀疏替換保持精確。移除上限時，129 處替換回歸會失敗，因為無上限實作返回精確統計，而非要求的完整片段退回。

## Consequences

瀏覽器建置包含 `diff`。上限約束編輯圖搜尋，不約束牆鍾時長：規範化、退回行及複製內容仍隨輸入長度增長，展開卡片也會單獨推導正文行。內容行規則把末尾換行視為終止符。迴歸覆蓋 256 次編輯時的精確輸出、超過上限後的完整粗粒度輸出、一萬行中的稀疏編輯、共享和遠距離上下文、重複行、複製字首及摘要與底部統計一致性。編寫和借用的 Session 快照分別覆蓋粗粒度和精確的瀏覽器卡片。
