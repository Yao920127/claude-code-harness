# Agent Note: 延遲顯示的 Windows 安裝視窗

Status: implemented

[English](2026-09-16-present-delayed-windows-installer.md) | 中文

## Problem

原生安裝程式準備資源時會隱藏視窗。如果使用者在此期間啟用其他應用，歡迎頁可能出現在該應用後面，看起來像沒有啟動。

## Decision

歡迎頁首次顯示時，安裝視窗會移到普通視窗前方，但不搶佔焦點。如果其他視窗位於前臺，安裝程式還會閃爍工作列按鈕，直至使用者進行前臺互動。後續頁面切換不會重複置前。安裝視窗不會永久置頂。

## Alternatives considered

**強制取得前臺焦點。** Windows 可能拒絕後臺程序的前臺請求，而且使用者切換應用後再搶回焦點會打斷目前操作。

**讓安裝視窗始終置頂。** 持續置頂會遮擋使用者在安裝期間主動開啟的其他應用。

## Consequences

準備完成時歡迎頁可見，使用者仍能控制焦點，也可以再次用其他視窗覆蓋安裝程式。原生視窗順序測試和簽名安裝程式冒煙測試覆蓋首次顯示。
