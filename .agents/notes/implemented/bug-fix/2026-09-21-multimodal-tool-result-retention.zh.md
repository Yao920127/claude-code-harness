# Agent Note: 工具結果的圖文保留

Status: implemented

[English](2026-09-21-multimodal-tool-result-retention.md) | 中文

## Problem

MCP 非同步準備持久化圖片，而純渲染器輸出文字佔位。在執行後策略完成後才安裝已準備內容，會讓文字保留使圖片替換失效。按位元組限制也無法比較文字與視覺輸入的成本。

## Decision

`ToolDefinition.projectContent` 在執行後策略之前安裝執行期間準備的內容。最終回呼保留其對終端和任務結果設定上限的獨立職責。策略阻止和替換仍然生效。

spill 策略以估算 token 對有序圖文塊計量，複用文字估算和目前模型圖片計算器，並計入說明文字。它預留省略提示，將剩餘 token 平分給連續兩端，省略中間。文字可在碼點之間切分；圖片不可切分，並保持原位置。

完整結果檔案按順序儲存已接受文字和可讀取的附件路徑。附件擁有圖片位元組。缺少圖片計量或可讀取的恢復路徑時，保留原結果並記錄診斷。PTC 程式回傳值保持完整；全部圖片被省略時，轉發內容和日誌仍保留讀取提示。

[spill 儲存決策](../architecture/2026-07-08-tool-output-spill-files.zh.md)繼續負責後端拆分和安全的本地檔案。[MCP 用戶端決策](../feature/2026-07-07-mcp-client-plugin.zh.md)繼續負責規範值和圖片准入。

## Alternatives considered

**在策略修改後恢復圖片。** 這可能恢復已阻止圖片或已丟棄文字。在策略之前準備內容，讓轉換能夠檢查真實圖片。

**圖片不計入預算或按固定上限計費。** 圖片必須與文字共享結果預算。現有模型計算器已經衡量請求尺寸和說明文字，因此由它負責成本。

**把圖片位元組嵌入 spill 文字。** Base64 會增大產物並重復附件儲存。可讀取的附件路徑在不複製位元組的情況下保留讀取方式和順序。

## Consequences

隨產品提供的結果預算為 12,500 個估算 token，替代此前的 50,000 位元組設定。文字計量仍為估算，提供者用量具有權威性。圖片分界處剩餘空間保持空閒，以維持連續的首尾內容。其他內容塊型別原樣透過。
