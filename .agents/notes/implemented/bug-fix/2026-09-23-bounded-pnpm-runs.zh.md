# Agent Note: 為停止推進的 pnpm 執行設界

Status: implemented

[English](2026-09-23-bounded-pnpm-runs.md) | 中文

## 問題

一次 profile 包操作可能永久持有 profile 寫鎖。某個 `dsh web` 程序在其 pnpm 子程序列印 `Done in 2s` 之後仍持有 `~/.dsh/profiles/web/package.json.lock` 達 22 分鐘：該子程序從未退出，於是操作等待一個永不到來的結束點，鎖始終未釋放，程序內後續每一次管理呼叫都排在它後面。pnpm 11.13.0 只消費一次性的 worker 池收尾，之後又惰性重建該池，並且只在銷燬時才對 worker 取消引用，因此該池會讓父程序一直存活，儲存庫側無從修復。

第二條成因以另一條路徑導致同一結果：繼承了 pnpm stdout 與 stderr 的生命週期腳本會在 pnpm 退出後繼續持有這些管道，於是等待檔案結束的讀取方永遠等不到，鎖在讀等期間一直被持有。

## 決策

- 執行的完成點是程序退出，而非管道結束。操作等待原始子程序的 `exit` 事件，並與 execa 的 promise 競速；後者只在管道化 stdio 關閉後才 resolve。
- 隨後管道在一個固定的 2000 毫秒寬限視窗內排空，視窗結束後由本次操作關閉它們。失敗分類讀取的是 pnpm 退出前寫入的尾部，因此該寬限屬於「完成一次執行」，而不是部署設定項。
- 只有本次排空造成的關閉才被忽略。切斷之前的讀取失敗仍作為該執行的失敗上報，日誌會記錄尾部被切斷。
- 捕捉輸出的執行若在 `idleTimeoutMs` 內沒有任何輸出即被終止，在自身退出狀態之外報告 `timedOut`，且不再詢問下一個註冊表，從而使單次操作持有鎖的時長有上界。
- 被終止的執行不論訊號留下什麼退出狀態都歸類為 `timeout`。安裝與刪除都報告失敗而非成功，因此 pnpm 只寫了一半的 manifest 會被還原，而不會被啟用。
- 被終止的執行會停止整棵程序樹並等待其消失，之後呼叫方才還原 profile 並釋放鎖，因為獲批的生命週期腳本是 pnpm 的子程序且存活更久。execa 的 `killDescendants` 覆蓋每一條 kill 路徑（含取消），且只對捕捉輸出的執行啟用，因此繼承終端的執行仍留在呼叫方的程序組內。
- `dsh plugin` 繼承呼叫方終端、不捕捉輸出，因此不受靜默上界約束，其操作者仍可中斷。

## 為何用靜默上界而非時長上界

只捕捉輸出、十分鐘沒有任何輸出的執行已經卡住：pnpm 自身的進度與腳本輸出都寫在那裡。而總時長上界會誤殺正當工作，因為非 TTY 的 pnpm 只在該腳本結束時才列印它的輸出，慢機器上的原生建置以超過任何可辯護固定預算的時間靜默編譯。靜默把卡住的執行與較慢的執行區分開，無需猜測時長；600000 毫秒給獲批建置留下的靜默餘量，是維護者預期的最慢靜默時長的十倍。

## 考慮過的替代方案

**等待 execa 的 promise。** execa 在管道化 stdio 結束後才 resolve，而那正是被持有管道扣住不發的結束點，因此完成訊號必須移到程序本身。

**改為對總時長設界。** 僅憑時長無法區分卡住的執行與正在編譯的執行，而且只要機器夠慢，這個上界就會破壞正當工作。

**只終止 pnpm 程序。** 獲批的 `postinstall` 會在操作報告超時並釋放鎖之後繼續寫入 profile，於是後續的還原與該腳本互相競爭。已用 pnpm 11.13.0 與一個 postinstall 會寫檔案的本地依賴復現。

**讓執行脫離父程序、稍後再回收程序樹。** 還原與釋放鎖必須在程序樹停止寫入之後發生，推遲迴收恰好留下本決策要關閉的那個視窗。

**保留管道作為完成訊號，只對該等待設界。** 排空確實為等待設了界，但卡住的 worker 池永不結束其管道，因此程序退出仍是完成訊號。

## 後果

- 卡住的執行最遲在 `idleTimeoutMs` 之後才被報告，profile 鎖在這段時間內一直被持有。靜默但健康、且超過預設值的原生建置會被終止並歸類為 `timeout`；需要編譯此類依賴的 profile 應提高 `idleTimeoutMs`，以更慢的卡住檢測換取容忍度。
- 被切斷的尾部不完整，因此失敗分類與返回輸出只看到 pnpm 在寬限視窗內寫入的內容。診斷日誌記錄了這次切斷。
- 終止執行會殺掉整棵程序樹，因此已經開始的生命週期腳本會被停止，而不會被允許跑完。
- 該上界是針對第三方缺陷的變通（issue #4981、PR #4982）；一旦 pnpm 在命令返回前完成其 worker 池收尾，它就不再必要。
