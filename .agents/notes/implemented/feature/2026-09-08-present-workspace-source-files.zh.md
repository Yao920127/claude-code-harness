# Agent Note：Present 宣告交付工作區原始檔

Status: implemented

[English](2026-09-08-present-workspace-source-files.md) | 中文

## 問題

使用者需要開啟並編輯工作區中產出的檔案，包括沒有編輯器修改記錄的 shell 產出檔案。儲存獨立交付版本會為這一流程增加內容儲存、副本驗證、臨時檔案保留，以及第二個編輯目標。

## 決策

[present 工具](../../../../packages/deliverables/tool-present/README.zh.md)宣告交付[Session 檔案系統存取策略](2026-09-09-present-filesystem-access.zh.md)允許的已有普通原始檔。它記錄路徑和可選說明，不讀取或複製內容。[交付外掛](../../../../packages/client/ui-deliverables/README.zh.md)使用 Host 預設應用開啟目前工作區原始檔。下次開啟會看到編輯後的內容；刪除或移動檔案會使宣告不可用。檔案內容保留與寫時複製儲存延期到有持久化設計負責時實作。

[工具說明](../../../../packages/deliverables/tool-present/README.zh.md#model-experience)指導模型選擇需要顯式交付的檔案。交付宣告與正文中的檔案引用各自獨立。錄製的 [SVG 交付情境](../../../../snapshots/web/present-svg/snapshot.yml)覆蓋生成檔案、交付事件和卡片。新錄製明確請求獨立檔案卡片，回放保留錄製時的請求。該情境驗證顯式交付，不要求所有 SVG 都呼叫 `present`。其 UI 快照覆蓋展開後的 Chat 對話內容；導航和輸入框控制元件由各自情境負責，避免無關介面改動使檔案交付預期失效。

工具保持為普通包，共享檔案系統和工具錯誤型別。其純型別入口擁有交付事件，不向瀏覽器匯入 Host 程式碼。`standard`、`ptc` 與 `cordis` preset 掛載工具；`minimal` 保持兩個工具。每個外掛實例將其執行與成功的最終 `tools/result` 通知關聯，再追加 `deliverables/presented`。原生與巢狀呼叫遵循同一規則。外層程式隨後失敗不會撤銷已完成的巢狀宣告；被阻止的結果不釋出宣告，同名作用域替換也不能釋出其他實例的結果。

經過認證的 POST 按目前檢視的 Session、事件序號和原始檔案索引選擇宣告。事件不攜帶所屬 Session ID；繼承歷史中的相對路徑按目前檢視的 Session 工作區解析。Host 在原生開啟前檢查普通檔案是否存在，並驗證 Host 路徑對映。路由釋放時取消並等待進行中的命令。[改動檔案卡片](2026-09-11-turn-changed-files-card.zh.md)在交付卡片旁列出本輪記錄的改動；兩個表面均不表示最終交付。

檔案卡片採用與 Session 頂欄相同的分段控制元件。點選卡片或左側“開啟”區域會在右側 Sidebar 預覽原始檔；右側箭頭開啟包含預設應用與檔案管理器操作的標準選單。Host 在 Finder 或檔案資源管理器中選中檔案，或透過 Linux 預設檔案管理器開啟所在資料夾。兩個原生操作都解析同一份已儲存宣告並驗證 Session 檔案系統與 Host 路徑；均不接受瀏覽器提供的替代路徑。來自 Host 的桌面資訊使遠端瀏覽器中的文案和可用性保持準確，路由在每次原生操作時執行設定的可用性檢查。單個交付佔滿整行；多個交付每行最多兩列，並保留所有宣告，前四張卡片之後的內容在使用者展開列表前保持收起。 桌面中繼資料隨連線代次失效，避免舊主機資訊讓原生操作持續停用或顯示錯誤的檔案管理器名稱。舊中繼資料請求會被取消，不能覆蓋新代次的回應。

## 考慮過的替代方案

**不可變附件快照和可編輯臨時副本**可在原始檔編輯或刪除後保留交付版本，但會使桌面編輯與工作區檔案分離，並在缺少目前產品需求時引入保留工作。本決策取代[快照交付設計](../../archived/feature/2026-09-08-web-explicit-file-delivery.md)。不保留下載端點或退回副本；兩者都需要未來明確的產品決策。

**直接開啟附件儲存檔案**會讓編輯器修改不可變物件。未來持久化交付系統需要先明確編輯和保留策略，例如寫時複製，再將儲存版本暴露給應用。

**通用 artifact 欄位或 UI 包內的 Host 工具子路徑**會擴充功能無關 API，或將 preset 安裝與瀏覽器打包耦合。工具擁有的事件與普通包保留現有擴充功能點和釋出規則。

**以工具文字作為持久索引**無法可靠應對後處理或結果溢位。執行身份與最終成功結果使宣告歸屬獨立於展示的工具文字。

**繫結檔案描述符的檔案系統擴充功能**會改動所有提供者，卻無法使外部桌面應用隨後按路徑開啟的動作原子化。目前檢查驗證檔案中繼資料和路徑對映；並行替換後復原仍不在路徑 API 的保證範圍內。

## 影響

Session 日誌持久化宣告，不儲存來自 `present` 的附件引用或檔案內容。Session ZIP 匯出包含這些宣告；轉移日誌不會轉移工作區檔案。該事件仍要求讀取端識別，因為靜默丟失交付宣告會改變重建或 fork 的歷史。已釋出 Session 格式代際保持不變。

僅宣告中繼資料不需要檔案大小上限，因此刪除該限制；可設定的檔案數量上限仍限制結果大小。卡片展示檔名稱與說明，沒有說明時退回到檔案型別，並且不展示可能過時的位元組大小。不引入 artifact 服務或推測性的儲存退回。

定向測試覆蓋不讀取內容的宣告、無效輸入、被阻止的結果、源路徑身份、編輯後的目前位元組、缺失檔案、工作區越界、fork 相對路徑、重試、取消與釋放。錄製的 Web 情境覆蓋巢狀成功後外層失敗、原始檔編輯、重新載入、刪除錯誤、卡片與正文開啟且無瀏覽器下載，以及不包含交付內容的 Session 匯出。
