# Agent Note: Web sidebar terminals

Status: implemented

[English](2026-09-09-web-sidebar-terminal.md) | 中文

## 問題

Web 使用者需要在 Session 旁使用互動式 shell 檢查工作區和執行命令。Agent 的持久終端工具控制提示符並等待語義結果；人工終端需要原始鍵盤輸入、正常 shell 設定和完整螢幕。命令仍在執行時，瀏覽器渲染和網路連線可能消失。

## 決定

開始頁入口宣告 provider 內穩定的 id。keyed `sidebar.right.tab.guide.entry` slot 按目前生效的 provider id 分發，因此替代 builtin 的 extension 也控制對應入口的渲染。側欄負責卡片排列和預設退回，provider 元件負責自己的控制元件，並透過框架 hook 讀取所在標籤頁。入口 slot 可以承載 shell 選單，無需替換整個開始頁或把互動按鈕巢狀在另一個按鈕內。

應用主題提供終端的預設顏色。終端正文讀取解析後的 CSS 權杖，僅在顏色變化時更新 xterm。公開的 OSC 解析觀察器將索引色和預設顏色覆蓋與 DSH 預設值分開儲存；重置命令先刪除對應覆蓋，再恢復目前主題。觀察器將查詢和顏色處理交給 xterm。xterm 的最小對比度調整改善文字可讀性，同時不重新對映 ANSI 背景色。DOM 游標在每次渲染後讀取單元格實際背景，透過區域性 CSS 變數使用有足夠對比度的填充色，因此游標移動不會重置調色盤。瀏覽器檢查覆蓋索引色、真彩色、反色單元格、明暗主題切換、OSC 保留和重置，以及閃爍游標樣式。

`api-terminal-controller` 按 Session 管理使用者終端並提供 `terminal` Remote namespace。`ui-terminal-panel` 使用 xterm.js 渲染終端並用 FitAddon 測量尺寸；[終端底部面板](2026-09-27-terminal-bottom-panel.zh.md)負責終端的顯示位置及其標籤頁的持久化，取代右側欄放置方式。面板的主操作開啟上次選擇且仍可用的 shell，獨立選單提供已安裝 shell。選擇選單項會記錄路徑並立即開啟新終端；僅探測 shell 不分配程序。每個標籤頁擁有自己的啟動和關閉生命週期。Host 探測會驗證設定的候選，並把執行環境預設項放在首位；建立只接受目前探測返回的路徑。瀏覽器在目前站點 localStorage 中記住上次選擇的 shell 路徑，該路徑不可用時回到目前預設項。雙擊標籤頁可重新命名終端。終端程序使用組合的 subprocess provider；[使用者終端權限](../architecture/2026-09-16-user-terminal-permissions.zh.md)規定其獨立於 Agent 的執行權限。shell 在探測和建立時解析；讀取限制和重新連線已有程序不依賴預設可執行檔案仍然可用。互動式 shell 設定提供 Tab 補全和可選的內聯建議。

關閉和替換會同步移除標籤頁，並在後臺清理程序。Client 先以終端獨立的 localStorage key 儲存未完成的關閉請求；成功後刪除，啟動時重試剩餘請求。清理失敗沒有通知或手動重試操作。已儲存面板之外的 Host 終端不會自動重新開啟，也沒有 UI 恢復入口。獨立 key 避免其他視窗覆蓋無關的清理請求。隱藏面板、切換標籤頁或 Session 和瀏覽器斷線均保留程序。元件清理只停止瀏覽器工作，因為外掛重新載入也會結束這一生命週期。程序清理失敗時保留所有權，包括分配完成但 create 尚未釋出時的失敗。Session owner 和 Host 外掛解除安裝也會清理終端。 明確的 Session 不存在回應會清除已儲存的關閉請求，因為程序清理由 Session 負責；傳輸失敗仍可重試。Client 外掛解除安裝等待所有斷開的流結束，避免替換外掛繼承未完成的 Client 清理。

[終端底部面板](2026-09-27-terminal-bottom-panel.zh.md)負責瀏覽器重新整理：先恢復每個 Session 面板的標籤頁，再重連其終端檢視。列表仍直接使用 Session ID，因為歷史記錄可以比 Agent 和終端 owner 存活更久；離線 Session 沒有需要恢復的保留終端。只有新檢視可以分配程序，恢復目標消失時顯示錯誤。程序狀態、標題和螢幕內容仍以 Host 為準。

呼叫者在建立之前保留終端 ID。相同 Session 和未關閉 ID 的重複 create 不再分配程序。建立結果不確定時，關閉仍使用該 ID，即使沒有收到建立回應。Host 在等待分配完成前記錄已關閉 ID，防止遲到的 create 復活已關閉終端。每次連線先接收一致、有界的 xterm 序列化螢幕，後續有序輸出使用 Gateway 已有的複用 Remote stream。輸出和螢幕快照共享操作佇列。訂閱者正常關閉時保留末尾輸出，快取超限時明確失敗。瀏覽器在完成渲染後確認幀，避免 React 批處理丟失增量。

最新連線控制輸入和尺寸，其他連線保持只讀。每次物理流建立都建立新的輸入連線標識，包括傳輸自動恢復。輸入 RPC 按序傳送，舊連線的結果不能把新連線降級為失敗。終端輸出不產生模型輸入、Agent 工具結果或 Session 事件。[Agent 持久終端決策](2026-07-16-persistent-pty-sessions.zh.md)仍約束模型擁有的終端；此功能為[可移植 subprocess provider](../architecture/2026-07-28-portable-execution-world-consumers.zh.md)增加執行環境事實和 resize。 控制權轉移和程序退出導致的拒絕只停用輸入，保留健康的輸出檢視。Client 自產錯誤標識由終端 UI 翻譯，包括名額用滿時關閉已保留的退出終端的提示。

## 考慮過的替代方案

**在瀏覽器儲存完整 shell profile。** 使用者偏好只包含選中的路徑。參數和可用性由 Host 探測決定；持久化這些資訊會讓過期 profile 繞過目前執行設定。終端列表和標籤頁控制元件由面板負責。

**程序清理完成前保留標籤頁。** 緩慢或失敗的終止會拖延使用者關閉操作。儲存清理意圖後，可以立即移除標籤頁，同時保留錯誤回饋與重試。

**持久化作為權威的活躍程序註冊表。** 瀏覽器程序狀態可能獨立於 Host 狀態失效。面板只儲存標籤關聯，同時保留 Host 對程序存活狀態的決定權。

**共用 Agent 終端註冊表。** 受控提示符和語義化 send/wait 會改變人工 shell 設定並混淆程序所有權。使用者終端只共享 subprocess 能力。

**增加專用終端 WebSocket。** 現有 Remote stream 已管理認證、取消和重連。第二條傳輸通道會重複這些職責。

**只重放有界原始位元組尾部。** 位元組尾部可能從轉義序列中間開始，或缺失備用螢幕切換。序列化終端螢幕能在保留有界歷史的同時提供一致恢復點。

**React 正文解除安裝時 kill。** 元件解除安裝、Session 切換和外掛過載都可能結束這一生命週期，而使用者並未關閉終端。清理必須跟隨顯式關閉操作。

**自建 Web 補全引擎。** shell 原生補全透過普通 PTY 輸入處理命令、路徑和已設定外掛。獨立補全介面需要針對 shell 解析和同步，不屬於此功能。

## 影響

保留終端會保留程序和有界螢幕記憶體。重新整理恢復每個 Session 的面板並重連 Host 保留的終端；Host 重新啟動不恢復程序。shell 退出後保持可見，不自動重新啟動。後臺清理可能比標籤頁存活更久，瀏覽器儲存不可用時只能在目前頁面保留重試能力。原生 PTY 支援和後代程序清理保證仍由 provider 決定。單一可寫連線避免競爭的輸入和尺寸流，顯式接管允許從另一頁面恢復操作。Session 的沙箱模式改變時，使用者終端保持開啟。

Agent 終端和可移植執行環境兩篇記錄仍保留，其所有權與 provider 決策繼續獨立有效，不被瀏覽器終端取代。

[無人連線終端的兩小時回收](2026-09-14-unattended-browser-terminal-reclamation.zh.md)在全部前端持有者斷開後設定空閒寬限期，保留忙碌或狀態不確定的工作。
