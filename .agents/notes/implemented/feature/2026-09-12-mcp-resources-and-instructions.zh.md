# Agent Note: 按需 MCP 資源與作用域伺服器指令

Status: implemented

[English](2026-09-12-mcp-resources-and-instructions.md) | 中文

## 問題

MCP 伺服器將文件與 URI 範本作為獨立於工具的能力暴露。只支援工具的用戶端無法讀取這些文件，也無法使用僅提供資源而不提供工具的伺服器。伺服器還提供指令來解釋各項操作如何配合；忽略這些指令會丟失選擇和組合操作所需的上下文。

## 決策

[`mcp-resources`](../../../../packages/mcp/mcp-resources/README.zh.md) 提供三個共享工具，用於列出資源、列出範本及讀取 URI。每個工具都要求顯式指定已設定的伺服器名稱。組合包含系統提示詞裝配時，字面段落從派發註冊表取得呼叫方可見的名稱，因此沒有伺服器指令的純資源伺服器仍可被發現。已有的系統訊息日誌記錄這些名稱；提供者釋放後，後續組裝會移除其名稱。執行路徑在派發前於呼叫 agent 的作用域中解析該伺服器；提供者註冊使用可撤銷的 Cordis effect。

[Profile 可用性決策](2026-09-13-mcp-resources-in-profiles.zh.md)取代單獨啟用資源服務的掛載方式，並擁有工具條件可見性。本筆記保留資源操作、結果表示與指令決策。每個 [`mcp-client`](../../../../packages/mcp/mcp-client/README.zh.md) 實例擁有自己的連線，並在服務已掛載時註冊資源提供者。伺服器缺少資源能力時，SDK 返回空的資源列表與範本列表；不受支援的讀取會失敗。伺服器無需宣告工具能力。官方 SDK 負責協定操作；列表遊標與資源 URI 保持不透明；顯式遊標請求一頁，省略遊標則由 SDK 彙總各頁。

資源結果為程式化呼叫方保留完整規範 JSON。Native 文字包含已設定的伺服器名稱及返回的 URI 中繼資料。字串值的 `blob` 欄位變為二進位制說明文字，不內聯 base64。已有的工具結果日誌記錄模型投影；本包不建立並行的資源日誌或二進位制附件儲存。

伺服器指令為每個已設定的 MCP 伺服器貢獻一個作用域內的字面系統提示詞段落。已有的系統訊息日誌記錄最終送達模型的組裝後指令。資源內容保持按需讀取，因此連線伺服器不會將其文件預載入到提示詞中。

本決策僅取代[原 MCP 用戶端記錄](2026-07-07-mcp-client-plugin.zh.md)中延後資源支援的決定。該記錄繼續保留在活躍目錄，因為其工具命名、規範結果、環境與傳輸理由仍然適用。Prompts 仍不受支援。

## 曾考慮的替代方案

**為每臺伺服器建立獨立的資源工具。** 不予採用，因為每臺伺服器都會增加另一套相同的操作 schema。三個共享工具保持較小的工具目錄；顯式伺服器參數與執行時的作用域解析負責選擇提供者。

**自動注入或重新整理資源內容。** 不予採用，因為資源列表無法確定任務需要哪些文件。按需讀取讓模型選擇內容，避免讀取無關文件，並保留實際使用過的結果。資源訂閱與更新通知仍未實作。

**將二進位制資源投影為原生內容。** 延後，因為圖片與音訊需要能力、持久化和呈現的協同支援。保留規範位元組並渲染中繼資料，可以提供實用的文字資源存取，而無需另建內容機制。

**為指令和讀取新增 MCP 專屬持久事件。** 不予採用，因為組裝後的系統訊息與工具結果已經記錄模型可見輸入。第二個事件權威會重複這些記錄。

## 驗證

[資源測試](../../../../packages/mcp/mcp-resources/tests/resources.spec.ts)固定了三個操作、原樣遊標、必填伺服器參數、不可用伺服器拒絕、作用域提供者選擇、重複註冊拒絕、釋放，以及保留完整規範結果但不向模型文字寫入二進位制的行為。它們還驗證無伺服器指令時呼叫方可見的伺服器名稱、名稱的字面保留，以及提供者或資源服務釋放時移除提示詞上下文。[工具結果契約](../architecture/2026-07-20-canonical-tool-output-contract.zh.md)擁有執行時值與已記錄模型內容之間的區分。

## 後果

僅提供資源的伺服器無需新增按伺服器區分的模型工具即可使用。呼叫方可見的伺服器名稱和伺服器指令增加提示詞 token；資源文件僅在讀取時增加 token。只要呼叫方可見的用戶端仍已設定，連線失敗期間共享 schema 就保持穩定，但所選伺服器不可用時呼叫仍會失敗。二進位制資源仍是程式化值，分頁遵循 SDK。
