# Agent Note: MCP SDK 協定協商

Status: implemented

[English](2026-09-12-mcp-sdk-protocol-negotiation.md) | 中文

## 問題

MCP 伺服器使用不同協定版本。圍繞舊版 SDK 實作發現與執行的工具橋接器可能遺漏現代請求 header、訂閱建立或協定驗證。

## 決策

`dsh-mcp-client` 使用官方 TypeScript client 2.0.0 並自動協商協定。SDK 負責現代發現與舊版初始化、按傳輸方式協商、列表變化訂閱、分頁、請求 header、取消與輸出驗證。橋接器使用高層 `listTools` 和 `callTool`，並向每次呼叫傳遞完整的發現定義。

橋接器保留伺服器限定名稱、原子註冊和持久圖片接納。未宣告 tools 能力的伺服器不釋出工具。發現失敗保留上一次成功註冊；重複名稱仍拒絕新註冊代。格式錯誤的遊標鏈會在 SDK 頁數上限處停止；橋接器不增加並行的分頁實作。

監督器在 SDK 將傳輸繫結到 Client 之前就持有該傳輸。釋放時先關閉未繫結的傳輸以取消協商，再等待連線嘗試結束，讓 SDK 回收探測程序。失敗的探測不會產生 Client 關閉事件；SDK 清理完成後，它使用正常重試預算。已繫結連線保留關閉事件屏障，防止伺服器程序重疊。

共享結果適應函式向每個提供者回呼傳遞原始 `ToolExecution`，保留其 Agent 身份和取消訊號。原生 Cua Driver 的結果會先透過 SDK 公開的規範型別驗證，再生成規範值投影；適應函式不接受另一種寬鬆結果格式。

[工具橋接記錄](2026-07-07-mcp-client-plugin.zh.md) 保留獨立的命名、作用域與圖片決策。本記錄調整其 SDK 實作，不替代這些決策。

## 考慮過的替代方案

**為相容性保留原始請求。** 這保留了寬鬆的錯誤結果處理，卻繞過 SDK 負責的現代 header 與 schema 驗證。有效協定輸出優先於舊式 `toolResult` 替代結果。

**在橋接器內實作現代協定行為。** 這會重複已維護的 SDK 行為，並增加一份相容性實作。

## 影響

Stdio 協商啟動可釋放的探測程序，並等待其退出後才啟動實際服務程序。SDK 透過頁數上限約束髮現，格式錯誤的結果會在投影前失敗。有效文字、規範 JSON、圖片接納、取消與註冊歸屬仍是橋接器的約定。隨附 profile 包含共享資源存取；elicitation、MCP 提示範本及任務執行仍不受支援。

真實 SDK 生命週期測試驗證探測釋放、程序順序、HTTP 探測重試預算及 stdio 啟動失敗。連線監督器測試保留已繫結傳輸的關閉屏障與有界失敗行為。
