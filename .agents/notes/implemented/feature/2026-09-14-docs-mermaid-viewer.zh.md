# Agent Note: 文件站圖表與圖片檢視器

Status: implemented

[English](2026-09-14-docs-mermaid-viewer.md) | 中文

## 問題

複雜 Mermaid 圖表和介面截圖縮放到文件正文列寬後，細節難以辨認。閱讀時需要在保留全圖概覽的同時放大和平移，以檢查互動細節。

## 決策

[VitePress 主題](../../../../website/.vitepress/theme/index.ts) 在每張已渲染的 Mermaid SVG 角落增加全螢幕圖示。原生模態對話方塊使背景不可互動，並支援 Escape 退出。可見標題也用於輔助技術識別對話方塊；頁面標題缺失或為空白時，使用在地化的檢視器標題。浮動工具欄集中顯示縮放控制元件、目前比例和適應視窗操作；關閉按鈕位於頂部角落，幫助按需展開。鍵盤焦點在五個按鈕之間迴圈。Panzoom 提供指標、滾輪和雙指互動。方向鍵按固定的螢幕距離平移。關閉時恢復入口焦點且不滾動頁面，並恢復頁面原有的 overflow 設定。

普通圖片與 Mermaid 共用一個彈層和縮放控制器。已載入、具有非空 alt 文字且獨佔段落的圖片支援點選圖片或角落按鈕開啟；連結圖片、行內圖片、裝飾圖片和 `data-no-zoom` 圖片保留原有互動。圖片的 alt 文字作為彈層標題，比例按鈕返回並居中顯示自然尺寸（100%），其輔助名稱同時包含目前比例；圖片檢視的鍵盤焦點在六個按鈕之間迴圈。

檢視器將 SVG 複製到 shadow root 中。Mermaid 內嵌的選擇器和片段 ID 限定在副本內部，因此副本的標記和樣式不會解析到原始圖表上。Panzoom 變換與視口等大的畫布，其中的 SVG 使用 viewBox 的自然尺寸，使指標座標與變換原點共享同一個中心；初始縮放以及每次視窗尺寸變化都會適應整張圖表，且不會放大到超出自然尺寸。這樣既保留向量細節，也使適應不受文件窄列寬度的影響。畫布沒有可見邊框；預留空間使控制元件不會遮擋適應後的圖表。

檢視器資源由已掛載的主題持有。路由、語言、主題和源內容替換都會關閉目前檢視；非同步渲染的 Mermaid 圖表和載入完成的圖片會獲得新的入口。body 的 overflow 滾動鎖依賴預設主題讓 HTML 元素保持 visible overflow。它避免修改 HTML 屬性，因為 Mermaid 外掛會觀察這些屬性並重新渲染。[共享彈層](../../../../website/.vitepress/theme/media-viewer.ts)、[Mermaid 介面卡](../../../../website/.vitepress/theme/mermaid-viewer.ts) 與[圖片介面卡](../../../../website/.vitepress/theme/image-viewer.ts) 將 Markdown、原始頁面副本和 `llms.txt` 的生成保留在原有歸屬處。

## 考慮過的替代方案

**加寬文件正文列。** 更寬的正文列無法讓任意大小圖表的細節都清晰可讀，長圖仍然會超出視口。

**使用自定義遮罩和文件級監聽器。** 原生對話方塊已經能使背景不可互動，並處理模態退出。由主題持有資源讓導航和資源清理的職責明確；持久的文件級監聽器則需要單獨的生命週期機制。

**點陣圖預覽或同文件內的 SVG 副本。** 點陣圖在高倍率縮放下會丟失向量細節。同文件內的副本會重複 Mermaid 的 ID 和內嵌樣式；重寫全部 SVG 和 CSS 引用會帶來額外的解析職責，而 shadow root 可以避免這項職責。

## 影響

文件站增加了 Panzoom 直接依賴，並使用原生 dialog、shadow root 和 ResizeObserver 支援。檢視器的縮放和平移狀態是臨時的：視窗尺寸變化會重新適應內容，導航或主題變化會關閉檢視。原有頁面圖片和圖表仍然是閱讀和連結導航的來源。

[Mermaid 測試](../../../../website/tests/mermaid-viewer.spec.ts) 與[圖片測試](../../../../website/tests/image-viewer.spec.ts) 屬於根單元測試集；`docs:check` 和 `doc-sync`（文件同步門禁）也會選中這些測試，使僅執行文件驗證時同樣覆蓋檢視器。它們驗證延遲渲染和載入、無障礙名稱、初始及視窗變化後的適應、100% 操作、鍵盤焦點迴圈、圖片與圖表互相切換、源內容替換和資源釋放。

**CI 覆蓋缺口。** DOM 測試模擬了 Panzoom，不執行瀏覽器佈局。原生模態行為、SVG 標記、以指標為錨點的滾輪縮放、畫布拖曳、主題顏色和窄屏幾何佈局需要真實瀏覽器驗證。瀏覽器演示記錄提供了目前實作的證據，但不屬於自動迴歸檢查。
