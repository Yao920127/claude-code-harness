# Agent Note: Bundled Office skills with structural verification

Status: implemented

[English](2026-09-15-bundled-office-skills.md) | 中文

## 問題

Office 任務需要針對檔案格式的編輯指引和可靠的檔案檢查。要求使用者安裝直譯器、包管理器或渲染命令列工具，會中斷普通文件交付。結構啟發式規則也可能在未觀察到實際版式缺陷時，誤拒有效的合併表格、多分節文件或中文文字。

## 決策

[Office 提供者](../../../../packages/skill/skill-office/README.zh.md)以內建優先順序提供三個可獨立發現的 skill（技能）。預設工作流使用 `load_workspace_dependencies` 及其 Python 可執行檔案；使用者和 AGENTS.md 明確指定的環境優先。可設定的絕對資源根目錄讓 Desktop 在應用歸檔之外暴露 Python 可讀取的資源。註冊時驗證必需資源與 YAML 描述；載入後的指令不包含中繼資料。解除安裝時移除全部候選項。

一個僅依賴標準庫的檢查器識別 Transitional 與 Strict OOXML 名稱空間，驗證 ZIP/XML 完整性與包內引用，報告各格式的結構，並只檢查明確指定的文字或數量斷言。損壞或加密的 ZIP 成員與其他無效文件一樣生成 JSON 包失敗報告。DOCX 表格摘要計算邏輯網格列數，包含合併單元格。分節幾何資訊僅報告，不以最終分節判斷全文；字型檔名不能證明字形覆蓋範圍。XLSX 公式數量不代表已執行重算。文字斷言跟隨分節與腳註／尾註引用及工作表字串索引，因此保留的頁首、未使用的腳註／尾註定義、批註、詞庫條目和未使用的字串不能滿足措辭要求。

Desktop 獨立於文件渲染掛載技能提供者和執行時查詢。Word 使用 python-docx，PowerPoint 建立和編輯使用 python-pptx，Excel 使用 openpyxl 和 pandas。受管理產物和普通建立範例都不要求渲染引擎或單獨的簡報創作庫。

缺少渲染服務時，Office skills 與內建執行時查詢仍保持註冊。視覺檢查取決於目前模型支援圖片且有可用渲染工具。否則，skill 完成結構與內容檢查，並在交付時說明未驗證的視覺範圍。`present` 引用工作區中的目前原始檔，不儲存私有副本。

## 考慮過的替代方案

**每次交付都強制要求計劃與本地渲染器。** 簡單編輯不需要固定計劃檔案，不支援圖片的模型也無法判斷渲染頁面。強制安裝渲染器會將可選品質訊號變成與許多請求無關的依賴。

**透過包結構與字型名猜測判斷版式。** 合併單元格、不同分節寬度、字型替換和應用排版規則，使這些觀察不足以證明渲染正確。檢查器報告事實，將視覺判斷留給實際影象。

**共用一個不區分格式的 Office skill。** 按格式發現可避免在 Word 編輯時載入公式指引，或在單元格更新時載入簡報指令。確定性檢查器仍然共享，因為三種格式採用相同的包引用規則。

## 影響

提供者提供可複用指令，不選擇或安裝部署執行時。檢查器可在受支援的 Python 標準庫可用之處執行，但不能證明 Office 渲染保真度、高階特性保留或公式結果。Loader 和解除安裝測試覆蓋資源重定位、啟用失敗與渲染服務缺失。錄製 Session 固定 Office 目錄與載入後的指令正文。檢查器測試覆蓋結構錯誤與 JSON 診斷；原生產物冒煙檢查透過內建直譯器執行複製後的檢查器。
