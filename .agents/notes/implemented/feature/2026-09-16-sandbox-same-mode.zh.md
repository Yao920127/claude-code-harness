# Agent Note: 重複沙箱模式無需審批

Status: implemented

[English](2026-09-16-sandbox-same-mode.md) | 中文

## 問題

模型可能在 `danger-full-access` 已生效時重複傳入 `sandbox_permissions: danger-full-access`。拒絕該呼叫會阻止已獲授權的工作，卻沒有阻止任何權限增加。

## 決策

當請求模式與生效模式相同時，`approveEscalation` 立即返回生效模式。工具仍要求參數成對出現。更寬模式仍需審批；更窄和不支援的目標仍然失敗。這部分取代了[沙箱決策](2026-07-06-sandbox.zh.md)中的非放寬請求拒絕規則；其約束與逐呼叫審批決策仍然有效。

## 考慮過的替代方案

**拒絕所有非放寬請求。** 即使沒有請求額外權限，冗餘參數也會導致呼叫失敗。

**再次請求審批。** 現有權限已經足夠，再次提示不會增加授權。

## 影響

Bash 和檔案系統工具無需審批服務或 agent 即可接受重複生效模式。共享單元測試覆蓋兩個已公佈目標，兩個工具消費方均執行重複模式，`fs-same-mode` ACP 快照驗證沒有審批事件的無限制寫入並檢查生成檔案。
