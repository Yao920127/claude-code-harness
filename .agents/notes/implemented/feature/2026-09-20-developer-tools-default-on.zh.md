# Agent Note: 偏好解析後預設開啟開發者工具

Status: implemented

[English](2026-09-20-developer-tools-default-on.md) | 中文

## Problem

新安裝需要直接使用開發者檢視、預設選擇、改動摘要和互動式 HTML 預覽，無需先尋找設定開關。已儲存的關閉偏好仍必須阻止這些功能在啟動期間啟用，包括髮生後無法撤銷的腳本執行。

## Decision

Host schema 將 `ui-developer-tools.enabled` 預設為 `true`。使用程序內偏好的遠端瀏覽器也從開啟狀態啟動。已儲存的 Host 值優先，包括 `false`。這僅取代[共享開發者工具設定](2026-09-17-developer-tools-settings.zh.md)中最初預設關閉的選擇；該記錄繼續負責共享持久化和渲染策略。

使用 Host 偏好的用戶端在收到經過 schema 解析並接受的值之前釋出關閉狀態。載入中、首次讀取失敗和名稱空間不可用均不授予互動式預覽能力。缺少儲存欄位時由 Host 提供預設值；用戶端不會把缺少回應解釋為允許開啟腳本。後續重新整理期間，已接受的值繼續有效。

只有 Trajectory 標籤頁受開發者工具偏好控制；第三方 View 保持可用。對話外殼保留顯式 Trajectory id，因為目前需求明確指定此 View。沒有現行需求要求任意診斷 View 共用該開關。

## Alternatives considered

**保持預設關閉。** 這可簡化初始介面，但新安裝現在直接提供的功能將需要額外啟用。使用者仍可儲存關閉偏好。

**在設定到達前讓 Host 用戶端預設開啟。** 這可以立即渲染，卻會短暫啟用使用者已關閉的功能。解除安裝可執行腳本的 HTML iframe 無法撤銷已經執行的腳本或請求。

**在 View 註冊中增加通用開發者工具標記。** 這會擴充功能外掛 API，並允許其他 View 加入目前僅針對 Trajectory 的開關。未來需求可以單獨論證該 API。

## Consequences

新 profile 在設定解析後展示開發者功能；已儲存關閉選擇的使用者保留簡化展示。新使用者也會獲得帶有[檔案系統讀取權限](../architecture/2026-09-09-workspace-file-read-authority.zh.md)所述能力的互動式 HTML 預覽。即使最終偏好為開啟，Host 初始化期間也可能短暫不展示開發者控制元件。

設定測試覆蓋首次等待、名稱空間不可用、顯式關閉值和程序內預設值。HTML 渲染器覆蓋驗證等待中及關閉偏好均不讀取關聯檔案，也不建立允許腳本的 frame。瀏覽器設定覆蓋驗證預設值和關閉選擇在重新整理後保持；文件預覽回放固定顯式關閉的情境。
