# Agent Note: 基於測量的 GitHub 託管 PR 預覽規格

Status: implemented

[English](2026-09-06-preview-hosted-runner-sizing.md) | 中文

## 問題

PR（Pull Request）預覽建置完整工作區及瀏覽器 worker VFS 映像。較低的每分鐘執行器價格不能保證較低的作業成本，因為 GitHub 將每個作業向上取整至整分鐘。將預覽移至持久化自託管機器還會改變隔離方式，不屬於本決策範圍。

## 決策

[預覽工作流](../../../../.github/workflows/build-preview-cloudflare.yml) 使用標準 GitHub 託管 `ubuntu-24.04`。建置、快取、部署、受保護映像驗證及評論語義保持不變。[規格參考](../../../../.github/preview-sizing/README.zh.md) 負責比較要求。獨立的 CI [故障切換手冊](2026-07-26-ci-failover-runbook.zh.md) 保留其執行器切換決策；預覽不使用這些開關。

### 測量

實驗 34012729982 的八種規格/快取組合及一個快取預熱作業均成功。每個測量作業檢出同一個實驗修訂，使用 Node 24.19.0 與 pnpm 11.7.0，並執行不可變安裝、完整工作區建置、預覽/VFS 打包，以及含 gzip 完整性驗證的本地上傳內容整理。熱作業恢復同一個執行私有精確 pnpm 快取；冷作業跳過恢復，但包含 pnpm 引導安裝檔案。不恢復編譯產物。

按[公開費率](https://docs.github.com/en/billing/reference/actions-runner-pricing)，測量作業合計 $0.504；60 秒標準預熱作業增加 $0.006。$0.510 總計算費用估算包含設定、恢復、測量上傳及清理，但不含儲存和帳戶折扣。在每種取樣快取狀態下，標準執行器比 16 核低 80.95%，比 4 核低 33.33%。相比對應的 16 核作業增加 78 秒。

標準作業提供兩個 vCPU 與 7.75 GiB 記憶體。工作區最大程序 RSS 為 2.86 / 2.76 GiB；預覽最大程序 RSS 為 0.76 / 0.74 GiB。兩者均未發生 OOM 或超時並完成。GNU time RSS 不是程序樹同時佔用的記憶體總量。這些樣本證明成功執行，而非永久記憶體保證。

比較固定原始碼、鎖檔案、命令和執行時版本，但不固定物理 CPU 或映像版本：標準與 4 核使用映像 20260831.293.1；8 核與 16 核使用 20260823.283.1。CPU 包括 AMD EPYC 9V74/7763 與 Intel Xeon 8370C/8573C。每種快取狀態的單個樣本測量所提供的標籤，而非獨立 CPU 擴充功能性或統計可重複性。

實驗不部署，也不存取 Cloudflare 憑證。測量上傳耗時零至一秒；熱快取恢復耗時六至十秒。作為背景，生產作業 101428009994 (run 34011495156) 在不同 SHA 上上傳耗時 14 秒、驗證一秒、評論兩秒。將該開銷加至本實驗屬於推算，而非已測量的標準執行器釋出結果。實際 PR 預覽工作流負責部署確認。

## 考慮過的替代方案

**保留 16 核。** 它提供最短的測量作業，但為 78 秒改善使每個樣本增加 $0.102。對於本次以成本為重點的決策，預覽建置不值得這項溢價。

**選擇 4 核或 8 核。** 兩者均成功並縮短建置，但取整後的樣本費用高於標準 Ubuntu。若未來工作負載耗盡標準容量，4 核可保留更多記憶體與磁碟餘量；這樣的變更需要新測量。

**移至自託管。** 因範圍限制而拒絕：預覽保留在 GitHub CI。現有 Linux 與 Windows 註冊實例可能共享持久化主機；其依賴、store 卷及清理假設不適用於全新的託管 VM。不改變故障切換或信任條件。

## 影響

預覽以約 78 秒取樣建置作業延遲換取更低的計算費用。生產 Cloudflare 延遲、映像釋出差異、未來建置增長及更廣泛的成功率仍是可觀測限制。不從本次單一實驗外推每小時或每月節省。最終檔案樹不包含臨時基準工作流及其安全測試；實驗提交與連結的執行保留方法和證據。

已執行的[針對性迴歸](../../../../scripts/preview-workflow.spec.ts) 固定託管路由、PR 觸發器與權限、不可變完整建置、只恢復快取、釋出內容整理、受保護映像檢查及冪等評論。實際修改為自託管路由會使路由斷言失敗；恢復後全部三個測試透過。不改變模型可見執行時行為，因此不需要修改 Session 快照。
