# Agent Note: 持久化 schema 策略與審閱

Status: implemented

[English](2026-09-17-persistence-schema-review.md) | 中文

## 問題

結構指紋能標識變化的持久化型別，但單憑指紋無法解釋共享變更，也無法區分已宣告的讀取承諾與對執行時行為的假設。由聯合型別位置和遍歷路徑生成的名稱還會因無關分支新增而變化，遮蔽審閱者需要檢查的欄位。

## 決策

Inventory format 2 在受影響屬性上記錄受支援的相容性中繼資料。中繼資料包含繫結、策略版本、字面量判別欄位、未知 kind 保留承諾和符合條件的歸屬 kind。帶策略的圖使用獨立指紋域；沒有繫結策略的圖保留 format-1 規範化和指紋。Inventory 版本描述 schema 工具，獨立於 Session 格式版本。

提取器僅接受核心擁有的 source 宣告上的顯式繫結，並要求每個使用位置具有 user 或 developer 字面量角色。生產者標記對完整 wire-kind 分組賦予資格。僅當雙方儲存的 schema 攜帶匹配承諾時，分類器才允許新增符合條件的歸屬 kind。已有 kind 仍須進行結構比較；刪除、追認資格、保留標識和無關破壞性變更繼續採用嚴格分類。執行時所有者在啟用繫結前實作並驗證承諾的保留行為。

沒有 JSON 值的可選屬性通常從提取圖中省略。當讀取器禁止某個屬性名時，`@persistenceReserved` 將該屬性顯式保留為可選 `never`。後續允許 JSON 值的定義因此屬於已有型別變更，而非新增可選欄位。標記僅接受可選 `never` 或 `undefined` 屬性上的單個無參數註解，並拒絕將屬性變為必選或允許 JSON 值的對映型別使用。

目前 inventory 將人工宣告名稱和原始碼位置保留為描述性中繼資料。結構摘要標識型別並提供目錄錨點。目錄按字面量 `kind` 對訊息源分支分組，並保留每個 `form` 分支、必需欄位、索引簽名及指向完整定義的連結。有界陣列標籤描述元素，不繼承最先到達該陣列的事件名稱。歷史參考保留凍結的渲染方式。

只讀 `persistence-review` 命令接受顯式的變更前後 inventory。它按摘要匹配未變 schema，僅當字面量判別欄位唯一標識分支時才匹配變化分支。有歧義的分支保留為獨立新增與刪除。共享結構證據列出每個受影響根，獨立章節保留權威分類器診斷。[歷史機制](2026-09-11-persistence-type-history.zh.md)繼續負責確認和版本要求。

## 考慮過的替代方案

**忽略所有 source 變更。** 訊息源可能承載回放或驗證語義。顯式且納入指紋的選擇加入約束受支援的例外，並使其他變更保持可見。

**將遍歷路徑用作型別身份。** 聯合型別位置和首個引用者路徑描述的是一次圖遍歷。無關插入和共享引用可能改變它們，而持久化型別並未改變。

**從相似欄位推斷重新命名。** 多個分支可能具有相同判別值或相似結構。保留有歧義的新增與刪除，避免將缺乏依據的對應關係呈現為事實。

**用可讀 diff 取代相容性檢查。** 審閱說明為讀者歸併證據，不能放寬分類器，也不能取代目錄內的確認歷史。

**保留每個 optional-never 屬性。** 未標記的 optional-never 屬性在已記錄 schema 中已經被規範化省略。改變該規則會影響無關指紋和歷史規範化；顯式保留僅記錄讀取器擁有的禁止規則。

## 影響

宣告的相容性承諾參與指紋，並在比較歷史快照時保持可用。工具不會推斷或強制執行時保留行為；啟用繫結的所有者提供該行為。普通註解、標籤和原始碼位置仍處於結構身份之外。

每份 inventory 繼續儲存完整巢狀 schema 圖。穩定標籤和分組審閱輸出減少展示噪音，不改變儲存編碼，也不重寫凍結歷史記錄。[實操手冊](../../../../docs/cookbook/reviewing-persistence-type-changes.zh.md)介紹審閱命令和確認流程。
