# Agent Note: 以證據指導簡化調研

Status: implemented

[English](2026-09-19-evidence-led-simplification-surveys.md) | 中文

## 問題

僅搜尋未使用的符號，可能漏掉實作成本超出必要結果的有效行為，也可能將沒有固定儲存庫呼叫方的公共擴充功能 API 誤判為死程式碼。原簡化 skill（技能）還將發現候選與冗長的歸檔流程混在一起，消費方範例遺漏應用與 Python 路徑，建議的提案結構也缺少必需的 `Alternatives considered` 章節。

## 決策

[簡化 skill](../../../skills/dsh-find-simplifications/SKILL.md) 追蹤從生產方到結果的完整路徑，判斷哪些區分會改變消費方動作，考慮明確收縮受支援行為，並尋找可以用權威讀取替代的持續維護副本。它區分組合可用性與部署策略，並在原始碼之外合計刪除的設定、生命週期、測試和文件成本。

生產使用會改變所需的取捨證據，但不會自動否決提案，也不構成實施授權。動態外掛發現、已安裝消費方、生成的執行時產物、profile、應用和 Python 都納入消費方追蹤。受保護的介面卡與持久化設計、已釋出資料、信任邊界、獨立 invariant 觀察、同步釋出、取消及達到靜止狀態的釋放仍是約束。

入口將判斷標準與[可選歷史參考頁](../../../skills/dsh-find-simplifications/references/historical-patterns.md) 分開，後者將機制與反例、殘留義務配對。歸檔操作仍由原有歸屬處負責，提案結構使用規範標題。

## 歷史證據

作者從 100 份英文已實作或歸檔簡化記錄中抽樣 26 份：11 份已實作、15 份歸檔。全部九份已否決簡化記錄提供反例。樣本涵蓋無生產方變體、無效請求開關、顯式輸入、公共投影、派生資料、共享組合、生命週期所有權和依賴替換；這是有目的的抽樣，並非隨機或窮盡審查。

凍結的比較輸入按空白分隔計數：基線入口為 2,222 詞，新版入口為 1,372 詞，參考頁為 897 詞；下方雜湊標識這些已測量產物。參考頁提供問題，而非目前刪除指令。所有介面卡都拒絕的開關不同於有效擴充功能 API；更簡單的公共狀態可以保留內部駐留差別；回饋時讀取會改變觀察承諾；依賴替換可能丟失確定性時鐘或必要的釋放行為。閱讀歸檔記錄時未追蹤或修復其出站連結。沒有編輯、歸檔或刪除任何舊記錄。

## 有界調研證據

原始碼快照固定為 #4618 之後的 master。每組使用繼承相同模型和推理強度的全新 agent（智慧代理），獲得相同歸屬領域、時間上限及每域最多四個提交項。發現候選的 agent 不能讀取其他輸出。執行時域覆蓋 `core`、`session`、`session-query`、`api`、`sdk` 和 Python；執行域覆蓋 `shell`、`subprocess`、`terminal`、`jobs`、`fs`、`mcp` 和 `boot`。

初始執行時結果產生後，增加第三個配對領域，覆蓋 `llm`、`compaction`、`context`、`skill` 和 `extensions`，以擴大覆蓋。該領域屬於探索性補充，採用較短但雙方相同的時間上限，與最初宣告的兩域比較分開。調研在這三個領域後結束。

skill 作者與目前候選隔離，根據歷史記錄撰寫修訂。協調者意外提前收到少量基線提示，但在新版執行前原樣接受獨立作者的修訂。交給獨立審查方的候選材料隱藏了分組標籤；協調者整合並非盲審。凍結輸入的 SHA-256 為：基線入口 `9830af2272a1a1c3832078f31a432c8abe0335a013bc6c248c072b388520e798`，新版入口 `3b101d16ae098855c9214ad7fed631a2f079b6078c83b49829ae87305f631a87`，新版參考頁 `9a6b674d1eeadb691481ea09838b211b8e94c94e5a8cd928726246b1c097b2b5`。

這些執行結束後，評審僅將 skill 中的「earns its place」改為「is justified」；沒有改變發現標準，也沒有重新執行發現測試。每份提示都要求精確原始碼/搜尋證據、生產方與消費方分類、記錄重疊、淨減少量、最強反對理由和驗收要求。審查對每個提交項使用相同標準，區分區域性編輯與長期決策，既不單憑公共可發現性，也不單憑刪除行數作結論。

基線產生六個原樣可用的長期提案，另有兩個調整後可用。新版 skill 產生三個長期提案和三個區域性清理項，一項行為收縮被暫緩。Python RPC 收縮和檔案系統 invariant 省略相互重疊。合併集合包含九個互不重複的長期提案；新版增加了[僅保留設定更新的 HMR](../../proposed/simplification/2026-09-19-config-only-hmr.zh.md)。該樣本未顯示新版的長期提案產出更高。

審查縮小了[查詢 API 提案](../../proposed/simplification/2026-09-19-trim-session-query-convenience-api.zh.md)，保留其字面子串語義不同於 FTS 的 `filterEvents`。[提示事件提案](../../proposed/simplification/2026-09-19-retire-prompt-registry-change-event.zh.md) 明確撤回目前擴充功能承諾，而非聲稱逐步驟組裝讓通知多餘。這兩項經調整的基線發現仍有價值，因此保留。

三個僅新版發現的區域性項分別是映像的提供者引用、複製的檔案系統結果，以及重複的組裝器順序狀態。它們單獨計數，沒有寫成目前設計提案。

審查暫緩了將自動 Session 引用大小改為固定位元組預設值的提案。[目前預算決策](../bug-fix/2026-09-05-session-reference-model-budget.zh.md) 修復了大型模型丟失有用上下文的問題；盡力而為的 spill 檢索不能替代內聯上下文。沒有新的工作負載證據支援恢復有問題的預設值。提案的刪除清單準確，但僅此不足以推翻目前要求。

## 考慮過的替代方案

**繼續以呼叫數量為主要篩選依據。** 這會遺漏生產方支援、動態消費方及有價值的明確行為收縮。更多符號匹配不能證明哪些義務可以刪除。

**將歷史成功案例編碼為刪除清單。** 架構與消費方會變化。參考頁使用機制與反例，不將凍結記錄視為目前權威。

**按提案數量選擇修訂。** 觀察到的數量不支援優越性結論。已展示的收益是互補發現和明確分類；更有價值的合併集合包含兩個版本的發現。

## 後果

skill 改變調研指導，不改變執行時行為。九份提案仍需限定範圍的實作與相關測試；本次未執行其未來實施檢查。三個區域性機會保留為評估發現，缺少依據的預算逆轉排除在提案集合之外。

每個版本/領域只有一次發現執行，沒有隨機順序或重複試驗，相同上限內的實際耗時不等，審查帶有判斷性。原始碼減少量是估算，並非實作 diff。這些結果不能證明統計優越性、可復現的提速或窮盡覆蓋。
