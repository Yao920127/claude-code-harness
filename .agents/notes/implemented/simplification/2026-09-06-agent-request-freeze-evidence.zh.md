# Agent Note: 僅複用迴圈已證明的訊息凍結

Status: implemented

[English](2026-09-06-agent-request-freeze-evidence.md) | 中文

## 問題

長工具對話在建構請求時反覆遍歷不可變歷史。[後端續跑基線](../testing/2026-09-06-backend-continuation-performance.zh.md)在一次 211.300 ms 的請求歷史操作中，將 132.876 ms 的取樣 CPU 自耗時歸因於 `buildRequest` 的 `deepFreeze`。跳過所有已凍結根物件並不安全：恢復操作會接管獨立擁有的物件圖而不凍結它們，淺凍結訊息仍可能包含可變內容。

## 決策

每個 `ReactLoopAgent` 擁有私有 WeakSet<Message>，其中只記錄該實例中完整 `deepFreeze` 呼叫成功的物件身份。每個未見訊息先原地深凍結，再加入集合。後續請求複用該證明。新迴圈會重新證明每個物件；訊息 id 相等不能證明物件身份相同。弱引用不會增加對已壓縮歷史的所有權。

迴圈每次請求都深凍結較小的本地規範化 header。`canonicalHeader` 共享巢狀值，`Session.append` 凍結的是獨立快照：兩者都不能證明本地 tools 或 `NO_ADAPTER` 退回中的 stop 陣列不可變。迴圈分別凍結新訊息陣列與請求封裝，保留 `markAgentLoopRequest`，並保持即時 `AbortSignal` 可變。恢復訊息的物件身份及其外圍事件包裝物件的可變性保持不變。

該決策專門最佳化請求建構，不改變 Session 所有權或通用 `deepFreeze` 行為。`Session.deriveMessages` 與 `fromRestore` 保持不變。LLM（大語言模型）的檔案、影象和回放投影保留各自的凍結，因為它們新生成的值沒有迴圈本地證明。[可重建請求決策](../architecture/2026-07-05-reconstructable-requests.zh.md)繼續擁有可觀察的不可變性與基於日誌的請求重建規則。

## 考慮過的替代方案

**`Object.isFrozen` 為真時立即返回。** 已凍結根物件不能證明其後代已凍結。在共享輔助函式中使用此捷徑會削弱所有呼叫方，包括恢復與投影路徑。

**信任所有 Session 訊息或快取訊息 id。** 恢復明確允許擁有獨立所有權的未凍結資料；替換操作可保留 id，同時改變物件身份與內容。只有對該精確物件完成遍歷才能證明請求要求。

**保留強引用 Set 或共享全域證明快取。** 強引用會延長舊歷史的生命週期。全域快取將所有權擴大到 agent（智慧代理）之外，對同一迴圈的重複請求並無必要。

**移除下游投影凍結。** 投影后的檔案／影象／回放訊息是擁有獨立所有權的不同值。最佳化它們需要獨立證據，不能由規範歷史已凍結推匯出來。

## 影響

請求建構仍掃描訊息身份並分配新陣列，但避免遞迴遍歷已證明的歷史。每個迴圈都為恢復歷史支付一次完整遍歷成本。本地 header 仍是每次請求的成本。訊息值、請求標記、先前請求快照、取消及 SDK 序列化輸出保持現有行為。

[聚焦測試](../../../../packages/core/agent-loop/tests/request-freeze.spec.ts)覆蓋具有可變後代的淺凍結恢復根物件、包裝物件身份與可變性、僅成功遍歷的證明、重複請求、同 id 壓縮替換、新迴圈、巢狀工具 schema、介面卡與 `NO_ADAPTER` stop 陣列、持有的舊請求以及即時取消。重建與取消測試集覆蓋相鄰迴圈語義。效能測量採用不變的[續跑工作負載](../../../../benchmarks/agent-continuation/workload.ts)，而非縮小的合成微基準。

驗證執行了 646 個 agent loop 與 LLM 測試，agent.ts 的語句、分支、函式和行覆蓋率均為 100%。無金鑰 TypeScript SDK bash-tool 與 multi-turn 快照透過重新建置的庫執行並透過。Python sdk-minimal 與 sdk-snapshot 檢查使用獨立打包的 node24-macos-arm64 可執行檔案並透過。兩個 SDK 均無需修改期望輸出。打包部署暫時移除了工作區依賴連結；執行凍結 lockfile 安裝可在原始碼檢查前恢復它們，無需修改受版本管理的依賴檔案。

現行不可變性、訊息身份、可觀察狀態機和後端基線說明仍各自具有價值；沒有說明被完全取代或歸檔。本文專門規定請求凍結機制，並與可重建性所屬說明交叉連結。
