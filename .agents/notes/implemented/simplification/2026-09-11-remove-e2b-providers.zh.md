# Agent Note: 移除 E2B 執行提供者

Status: implemented

[English](2026-09-11-remove-e2b-providers.md) | 中文

## 問題

E2B 實驗為檔案工具、Bash、PTY 和語言伺服器提供了一個遠端檔案系統／程序世界，而 Harness、憑證、模型傳輸和工作階段狀態留在主機。三個提供者證明，這些消費方可以共享現有檔案系統與子程序介面，無需特定於提供者的工具。

PTC Node 約束需要獨立於任意程式 stdin/stdout/stderr 的雙向控制通訊。固定版本的 `e2b@2.29.1` SDK 提供標準程序流與 PTY 輸出，沒有額外描述符傳輸。在 VM 中建立描述符不會使其暴露給 Harness 主機；必須透過遠端中繼或獨立的認證流進行橋接。

這樣的橋接負責輸出阻塞時的獨立推進、有界保留、通道關閉、啟動釋出、命令身份、取消和斷線清理。即使消費方施加反壓，SDK 仍保留完整的 stdout/stderr，因此僅限制流級佇列無法約束主機記憶體。擴充功能這一介面卡會把實驗變成獨立的遠端傳輸專案。

## 決策

儲存庫不包含 E2B 沙箱所有者、檔案系統提供者和子程序提供者，也不包含其 SDK 依賴、整合 fixture、可選工作流和生成註冊項。儲存庫不提供 E2B 執行後端。移除用放棄該整合換取更小的維護範圍；這不意味著 E2B 無法支援合適的傳輸，也不意味著已釋出包沒有外部使用者。

[可移植執行世界決策](../architecture/2026-07-28-portable-execution-world-consumers.zh.md)繼續負責 `ctx.fs` 與 `ctx.subprocess` 的約定。兩者描述同一個路徑名稱空間與程序世界。提供者負責路徑轉換、可執行檔案查詢、普通流、終端分配和受管清理；消費方保留工具語義、策略和呈現。local/remote 中繼資料標籤不會為這些操作增加權限依據。

遠端執行仍是預期能力。終端分配、寫入、前臺檢查和訊號傳送保留 Promise 約定，以及待處理操作的取消保證。本地實作同步完成這些呼叫，不足以支援移除遠端提供者所需的非同步行為。程序完成、終端就緒判斷、模擬器解析和受管範圍停穩也保留現有職責歸屬。

本決策移除一個提供者族。它既不改變 PTC 執行，也不改變共享檔案系統、子程序和終端介面。直接 Node 約束與程式生成的控制通訊驗證需要各自的實作和證據。

## 考慮過的替代方案

**保留 E2B 並拒絕控制通道請求。** 這隻需少量新傳輸程式碼即可保留現有遠端功能，但仍保留 SDK 與遠端生命週期維護責任，同時排除新的執行能力。移除明確表達這一維護取捨。

**透過 E2B 標準流多路複用通道。** 中繼可以對 stdin/control 輸入和 stdout/stderr/control 輸出分幀。它還需要逐通道流量控制與關閉、有界佇列，以及累計 SDK 輸出保留的解決方案。這些是遠端傳輸語義，不是描述符接線。

**使用獨立的認證流。** 這可以避開 SDK 保留輸出的路徑，並讓控制通訊獨立推進。它增加端點存取、認證、網路策略、啟動協調和連線失敗清理。本次移除不引入該傳輸。

**把終端操作改為同步。** 這可以簡化本地包裝，但會移除遠端提供者需要的延遲操作行為。共享非同步介面及其取消／排序測試在沒有 E2B 時仍然有用。

## 後果

依賴儲存庫 E2B 包的自定義組合失去該後端。外部採用情況未知。移除整合也會移除其真實遠端組合證據；保留的本地與延遲提供者測試保護各自約定，並不驗證尚未實作的替代方案。

[原生約束](../architecture/2026-08-28-subprocess-native-containment.zh.md)、[出站代理](../architecture/2026-08-27-outbound-proxy-policy.zh.md)和[工作區檔案服務](../architecture/2026-09-05-workspace-files-service.zh.md)決策保持有效。它們的 E2B 實作與驗證清單被撤下，程序所有權、路由和檔案存取要求保持完整。可移植性決策僅有 E2B 實作部分被取代。

## 重新引入條件

遠端提供者需要具體的執行案例，並證明共享檔案／程序座標、策略強制、有界傳輸保留、獨立控制推進、精確通道關閉和受管取消。原始碼與建置後組合必須執行這些行為。連線丟失不能成為重放可能已執行程式的理由，也不能據此聲稱未觀察到的清理已經成功。

[POSIX SSH 提供者](../architecture/2026-09-11-posix-ssh-runtime.zh.md)使用獨立於 E2B 命令 SDK 累計輸出保留路徑的二進位制通道。普通 SSH exec 不對映任意子程序描述符，因此其遠端輔助程式負責控制流橋接、檔案語義、程序生命週期及遠端策略執行。該實作使用保留的介面；E2B 整合繼續退役。

## 驗證

移除清點未發現有效的 E2B 包、工作流、匯入、依賴或目錄條目。鎖檔案中每個保留的 importer 與包解析結果都保持原值。共享子程序與終端實作、延遲提供者測試和 PTC 原始碼保持不變。

保留的檔案系統、子程序、Bash、終端與 LSP 套件，以及受影響的生成器與工作流測試均透過。移除後的 `pnpm run build`、`pnpm run test:docs`、`pnpm run doc-sync`、`pnpm run lint` 與 `pnpm run hygiene` 均透過。這些檢查驗證得到的程式碼樹；已刪除的 E2B 測試不為其提供證據。
