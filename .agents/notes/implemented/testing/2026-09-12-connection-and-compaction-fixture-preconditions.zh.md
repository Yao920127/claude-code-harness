# Agent Note: 連線與壓縮測試夾具的前置條件

Status: implemented

[English](2026-09-12-connection-and-compaction-fixture-preconditions.md) | 中文

## Problem

重連標籤可能在懸停顏色仍處於過渡期間出現。壓縮壓力可能選中比檢查點必需格式還短的初始指令。僅憑其中任一觀察，都無法確定測試要斷言的狀態已經成立。

## Decision

[連線恢復測試](../../../../apps/web/tests/lifecycle-chrome.e2e.ts) 從獨立元素讀取警告顏色 token，再輪詢指示器計算後的前景色與背景色，直到兩者都等於相應 token。瀏覽器 CSS 過渡與被模擬的 JavaScript 重試計時器使用不同的時鐘。這遵循[夾具完成條件決策](2026-09-08-ci-completion-observations.zh.md)：中間視覺狀態不能滿足最終斷言。

[壓縮冒煙測試](../../../../apps/cli/tests/profiles/headless/tests/compaction.e2e.ts) 完成每一輪檔案讀取後才提交下一輪。每個檔案將包含編號的句子重複 200 次，共 4,600 個字元。8,000 token 的合成上下文視窗在用量達到 50% 時觸發壓縮，因此壓力閾值為 4,000 token。一次夾具測量中，完成一次讀取後的請求用了 2,738 token，其中 1,274 token 位於對話 surface 之外。一次失敗的校準執行選中了約 60 token 的初始指令，卻生成了包含格式在內的 475 token 檢查點；執行時正確拒絕了這個更大的替換。分開的已完成輪次避免四次讀取全部成為一個被保留的工具組。失敗輸出包含已記錄的壓縮錯誤，同時測試仍要求產生摘要、替換歷史並給出最終回答。

## Alternatives considered

**等待固定時長或停用瀏覽器過渡。** 固定延遲不能觀察完成狀態；停用過渡則移除了失敗所涉及的生產行為。

**增大超時或接受未縮小的檢查點。** 更多時間不能使短指令大於檢查點格式。執行時仍必須拒絕未縮小的檢查點。

**只增大合成上下文視窗。** 模型仍可能將讀取合併到一個被保留的工具組，使更早的歷史中沒有足夠內容可供摘要。

## Consequences

產品行為、CSS、壓縮接受規則、已記錄快照、重試次數與測試截止時間保持不變。真實提供者冒煙測試透過額外的顯式輪次建立較舊歷史；瀏覽器夾具透過相同的精確顏色斷言觀察動畫完成。
