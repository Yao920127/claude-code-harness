# Agent Note: 跨重新啟動保留已安裝 Desktop 的更新證據

Status: implemented

[English](2026-09-14-desktop-installed-update-journal.md) | 中文

## 問題

已安裝應用的更新會替換應用檔案，並退出觀測下載的程序。僅有終端輸出無法串聯傳輸失敗、顯式重試、安裝授權與下一版本啟動。原始 updater 診斷可能包含私有 URL 或憑證。

## 決策

Desktop 主入口接受顯式啟用的絕對路徑 `DSH_DESKTOP_UPDATE_JOURNAL_DIR`。驗收包必須在不同版本間保留同一個外部目錄。每個程序獨佔建立單獨的 JSONL 檔案，並在繼續執行前重新整理白名單內的狀態與操作記錄。已安裝版本、PID、序號和 UTC 時間標識記錄。整數進度變化限制重複寫入；原始錯誤、URL、請求頭和聊天內容均被省略。已知錯誤標記產生固定分類，不複製診斷文字。

未設定該變數時不啟用日誌。顯式啟用的驗收儲存失敗會向上傳播，不會靜默聲稱證據完整。啟動和工作區就緒只是觀測結果，不能證明安裝成功或使用者資料保留。[本地驗收決策](2026-09-10-desktop-local-updater-qualification.zh.md)繼續有效：本日誌不取代其隔離要求、安裝攔截的侷限或硬體限制。

[安裝版批次工具](../../../../apps/desktop/scripts/installed-update-qualification.ts)建立獨立 test 清單，不讀取憑證或執行遠端操作。其只讀檢查器要求同一原程序內按序記錄失敗、手動重試、就緒、確認和退出，再記錄後繼版本啟動與工作區就緒。未知欄位、不完整記錄、序號缺口與混合程序身份均被拒絕。即使記錄流程完整，也保留髮布時間、網路恢復、安裝器完成和資料保留的獨立人工檢查；一組啟動日誌不能代替這些觀測。

## 考慮過的替代方案

**僅保留終端輸出或安裝目錄內的檔案。** 安裝會替換應用檔案，新程序也可能在終端結束後繼續執行。證據目錄保留在安裝目錄樹之外。

**儲存任意日誌並對已知秘密脫敏。** 未知認證值和私有路徑無法窮盡列舉。欄位白名單保留的細節較少，但排除了這些字串。

## 結果

日誌收集只讀取一次透過驗證的位元組，並從這些位元組生成儲存檔案和里程碑報告。分別為各輸出重讀變化中的原始檔，可能報告儲存日誌中不存在的觀測。每次收集使用新目錄並記錄檔案雜湊；舊收集和源日誌不變。在位元組進入收集目錄前，檔案讀取器也檢查固定診斷值，而非僅依賴寫入器。輸入無效時拒絕收集；儲存失敗保留部分證據，不宣稱完成。完整的里程碑序列仍將人工驗收保持為待確認。

日誌與主入口測試覆蓋持久化、重試標記、不同版本的獨立檔案、私有欄位省略和儲存不可用。已安裝應用重新啟動、安裝完成、資料保留與網路故障注入仍需人工驗收。日誌不會自動刪除；操作者負責保留記錄，並必須拒絕證據缺失或不完整的結果。日誌不會清除簽名鎖定或授權安裝。
