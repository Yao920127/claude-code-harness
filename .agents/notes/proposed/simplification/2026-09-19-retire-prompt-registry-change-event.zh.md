# Agent Note: 停用提示詞註冊表變更事件

Status: proposed

[English](2026-09-19-retire-prompt-registry-change-event.md) | 中文

## 問題

[`SystemPrompt`](../../../../packages/core/system-prompt/src/index.ts) 在提供者註冊或 dispose（資源釋放）時發出 `system-prompt/change`。儲存庫搜尋未找到執行的產品監聽者，但生成的 Host 發現目錄會展示該事件。測試維護通知次數及監聽者丟擲異常後的復原行為。即使沒有第一方訂閱者，它仍是具有維護義務的公開擴充功能。

活動的 [Remote 事件投遞決策](../../implemented/architecture/2026-08-10-remote-event-delivery.zh.md) 明確保留了這一擴充功能，儘管沒有隨產品提供的消費方。逐步驟組裝早於該承諾，且用途不同：重新建置模型輸入不能替代註冊表變更的推送觀測。

## 提案

停用 `system-prompt/change`，接受已安裝及動態編寫的 Host 外掛失去提示詞註冊表推送觀測的代價。刪除其宣告、發出點、目前文件、生成的發現條目和通知專屬測試。目前受支援的產品路徑均不依賴此擴充功能。

將 [`ScopedLayers`](../../../../packages/core/scope/src/store.ts) 建構函式的通知回呼改為可選，並讓 `SystemPrompt` 省略它；不提供無操作回呼。更新此共享建構函式時，同時刪除 [jobs-local](../../../../packages/jobs/jobs-local/src/index.ts) 和 [mcp-resources](../../../../packages/mcp/mcp-resources/src/index.ts) 中現有的無操作實參，並更新 jobs-local 相鄰的通知說明。保留共享 effect、操作復原、撤銷順序、層回收，以及 `tools/change` 及其生產消費方。保留提示詞提供者求值、作用域覆蓋和組裝 invariant。

實作時必須修訂活動的 Remote 事件投遞記錄，說明本提案只取代其中保留 `system-prompt/change` 的承諾。從保留擴充功能的陳述中移除該事件，並連結到已實作的停用決策。讓 Remote 投遞記錄保持活動並相互連結：其轉發策略和其他擴充功能仍具有獨立價值。不要重寫或歸檔整個決策。

## 考慮過的替代方案

**為未來儀表盤或外掛保留擴充功能。** 推送觀測可能服務於真實消費方，但受支援的產品路徑中尚未找到這樣的消費方。保留它會維持這個包原本不需要的通知及監聽者失敗行為。

**將逐步驟組裝視為相容性證據。** 不採用，因為模型輸入重建和註冊表通知是不同的行為。本提案有意改變擴充功能承諾，而不聲稱早先的重建決策已經刪除了它。

## 驗收標準

- 從原始碼和目前生成目錄中刪除該事件，並在實作變更中修訂活動記錄中的保留承諾。
- 刪除通知次數和通知失敗測試；保留提供者成員關係、disposer、重複註冊、作用域覆蓋及 HMR（熱模組替換）覆蓋。保留混合測試中的獨立斷言。
- 執行針對作用域、工具、系統提示詞、jobs-local 和 mcp-resources 的測試、迴圈請求重建覆蓋、相關無金鑰錄製回放、目錄生成、型別檢查、lint 和 doc-sync（文件同步門禁）。提示詞和日誌輸出保持不變。

## 風險

已安裝外掛可能依賴通知，或依賴監聽者異常使註冊失敗。這兩種行為都會消失；儲存庫搜尋無法確認此類外掛不存在。未來的推送消費方需要先明確註冊觀測需求和所有權設計，才能重新引入事件。原始碼節省不多；收益在於停用公開通知及其失敗義務。
