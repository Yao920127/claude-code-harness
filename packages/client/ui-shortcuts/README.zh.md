# @deepseek-ai/dsh-client-ui-shortcuts

[English](README.md) | 中文

## 概述

檢視目前視窗可用的命令，按操作名稱、英文別名或鍵位搜尋。從通用設定或 Mod+/ 開啟速查。錄製、清除或恢復應用快捷鍵；固定輸入操作保持只讀。

## 使用此包

Web 應用 bundle 將此包與 `shortcuts` 一同掛載。速查僅展示已註冊命令和現有固定輸入操作。桌面端展示裝置對應的有效鍵位；沒有 Web 預設鍵位的命令顯示“暫無快捷鍵”。設定入口與 Mod+/開啟同一個單實例彈出視窗，中文標題為“快捷鍵”，英文標題為“Keyboard shortcuts”。卡片尺寸為 480×600 CSS 畫素，小視窗中縮小以保持可見；標題和搜尋框位於內部滾動列表上方。開啟時聚焦搜尋框，邊框顏色保持不變。速查窗、錄鍵框及重置確認框內的自動進入和回焦均不繪製外輪廓線，包括透過 Esc 和應用關閉快捷鍵觸發的回焦。容器仍不繪製焦點外框，Tab 和方向鍵導航保留可見焦點提示。設定入口標為“編輯快捷鍵”，快捷鍵提示文案為“全域喚起檢視”，使用與相鄰設定控制元件一致的標準圓角填充按鈕，不帶下拉圖示，並從同一有效繫結讀取提示及 `aria-keyshortcuts`；沒有繫結時不顯示提示，也不設定該屬性。

沒有模態彈出視窗或設定位於最前方時，`Mod+/` 開啟速查；速查位於最前方時，該快捷鍵關閉速查。速查位於前方時，設定命令不能開啟或關閉設定。長按產生的重複按鍵不執行操作。錄鍵期間、寫入尚未完成或巢狀確認框開啟時，速查快捷鍵不會關閉彈出視窗。

核心操作採用固定產品順序，不受外掛註冊、解除安裝或重新掛載影響。停止目前回覆位於“訊息輸入”分組末尾，仍為只讀項。未列入該順序的擴充功能命令在核心操作之後按命令 ID 穩定排列；其餘固定操作保留原有分組。

搜尋在單個操作名稱、英文別名或按鍵組合內按字元順序模糊匹配，忽略大小寫。每個命中命令只出現一次。搜尋時優先按相關性排序，同分項保留展示順序。正常顯示和錄製時，應用操作行和固定操作行均保持 42 CSS 畫素高；過長的命令名稱會被截斷。應用命令列只顯示名稱和改鍵控制元件，不顯示可用性副標題或原因懸浮提示，衝突和無效繫結也不例外。無法執行的命令靜默結束。兩個平臺均將可編輯行的完整快捷鍵放在同一個設定控制元件灰色色塊中，使用次級文字色。固定操作使用無背景的三級文字色，不能進入錄鍵，懸停時不高亮。分組標題與命令名稱左對齊。

懸停應用操作行時，整行顯示圓角高亮並露出編輯圖示；鍵盤聚焦也會顯示該圖示。點選行內任意位置進入行內錄鍵。未繫結的命令不顯示行內“移除”按鈕。Windows 和 macOS Desktop 可錄製一至兩個按住時間重疊的非修飾鍵，可搭配修飾鍵；第三個鍵會使草稿被拒絕。釋放第一個鍵即儲存目前組合，因此先後按 A、B 只錄入 A。儲存會拒絕被可編輯或固定操作佔用的組合，包括相互重疊的單鍵與雙鍵繫結。彈出視窗關閉控制元件可退出錄製。錄製框與鍵位標籤保持相同高度，使用中性灰邊框與次級文字色。其他環境保留 Escape 取消和 Tab 導航。儲存及取消後焦點返回彈出視窗。點選行內編輯區外的彈出視窗空白處會關閉編輯區，並丟棄尚未釋放的組合；點選編輯區內的狀態文字會保留草稿。macOS Web 可錄製被報告為 dead key 的 Option+Command+N；輸入法組合和普通重音輸入仍受保護。移除清空繫結，恢復預設只刪除該命令的覆蓋。系統提示回饋儲存成功和失敗；組合被拒絕時，錄鍵框顯示錯誤邊框。鬆開非修飾鍵後即可直接錄入新組合，無需再次點選，修飾鍵可繼續按住。同一錯誤重複發生時沿用仍在顯示的提示及其消失時間；不同錯誤和儲存成功立即替換提示。提示消失後，同類錯誤可再次顯示。寫入失敗保留錄鍵框焦點和草稿，可重試儲存或直接錄入新組合。設定或命令目錄變化後，需要核對最新設定才能重試草稿。讀取失敗時停用編輯，並透過系統提示說明目前使用的鍵位及受影響的設定位置：Web 使用目前來源的 localStorage 項 `dsh.keybindings.v1`；Desktop 使用 `userData/keybindings.json`。內容損壞時先備份並修復設定，再重新整理頁面或重新啟動 Harness；設定由更新版本寫入時應升級 Harness。“恢復全部預設”不會覆蓋無法讀取的資料。底部顯示“恢復全部預設”和目前執行環境及平臺的自定義項數，包括已移除的繫結和目前未掛載的命令。搜尋不影響計數。沒有自定義項時隱藏計數，並停用該操作。確認框預設聚焦“取消”；取消後焦點返回“恢復全部預設”，從錄製框開啟確認時也如此。確認後僅恢復目前設定分組。設定版本過期時關閉確認框，需要針對最新設定重新確認；寫入失敗保留已接受的繫結，允許重試。

## 理解實作

<details>
<summary>實作細節——點選展開</summary>

通用設定入口與 shell 彈層共享一個已宣告的互動 store。目錄與設定透過注入的 observable hook 更新；錄鍵和持久化使用注入的服務回呼。共用模態元件負責頂層 Esc、Tab 導航和關閉後恢復觸發控制元件焦點。

所有固定操作均來自服務的可觀察固定目錄。Conversation 和審批外掛貢獻各自的操作；本整合貢獻共用選單操作。行內容跟隨語言更新，並在其註冊被釋放時移除。

</details>

## 已知限制與延期工作

<a id="known-limitations-and-deferred-work"></a>

- 載入或解除安裝命令 owner 會使開啟的錄鍵草稿失效，即使已儲存的覆蓋沒有變化；重試前需核對目前鍵位。
- 錄鍵使用物理位置和美式鍵盤名稱。瀏覽器組合受[快捷鍵服務](../shortcuts/README.zh.md)限制。審批和雙 Esc 停止行只由已掛載的功能 owner 貢獻。
